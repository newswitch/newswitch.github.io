# 历史目录迁移

迁移脚本是一次性工具，面向当时的源目录，不是日常内容生成器。当前目录已经迁移，不能直接重跑来“同步网站”；网站构建会读取现有 `docs/`。

`scripts/migrations/` 中五个较早的迁移脚本需要显式 `--allow-historical-migration` 才能启动。该开关只用于复现历史环境，不保证脚本适用于当前仓库；运行前必须核对源版本、目标路径、备份和文件差异。
