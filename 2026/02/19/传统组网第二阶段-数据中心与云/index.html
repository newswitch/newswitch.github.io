传统组网第二阶段：数据中心与云

传统组网第二阶段：数据中心与云

核心目标：读懂 Spine-Leaf 拓扑的灵魂，吃透虚拟化网络。

1. VXLAN & EVPN 数据中心网络

核心学习内容

  1. 传统数据中心网络痛点、Spine-Leaf 叶脊架构设计核心逻辑
  2. Underlay 物理网络规划（OSPF/IS-IS、ECMP 等价路由）
  3. VXLAN 隧道封装原理、VNI 虚拟网络标识、Overlay 虚拟隧道转发机制
  4. EVPN 控制平面核心（7 类路由类型、MAC/IP 地址通告、ARP 抑制、IRB 集成路由桥接）
  5. 集中式 / 分布式网关部署、大二层互通、多租户隔离、VM 迁移无感知实现
  6. VXLAN 双活、DCI 数据中心互联、VXLAN 故障排障全流程

必做实操项目

  1. 搭建 2 Spine + 4 Leaf 的标准 Spine-Leaf 数据中心拓扑，完成 Underlay 网络规划与部署
  2. 基于 EVPN 作为控制平面，构建 VXLAN Overlay 网络，实现分布式网关、3 个租户的完全隔离、跨 Leaf 大二层互通
  3. 验证虚拟机跨 Leaf 迁移业务无中断，完成 VXLAN 隧道不通、EVPN 路由发布异常、跨子网互通故障等排障

验收标准

  • 彻底掌握现代数据中心网络的标准技术，能独立完成 Spine-Leaf 架构的规划、设计与部署
  • 能清晰区分 Underlay 与 Overlay 的边界与转发逻辑，灵活实现大二层互通与多租户隔离
  • 能独立完成 VXLAN EVPN 全场景的故障定位与排障

配套学习资源 / 工具

  • 工具：EVE-NG 模拟器（华为 CE 系列 / 思科 N9K 系列数据中心交换机镜像）、Wireshark
  • 书籍：《VXLAN 技术与实践》《数据中心网络架构与技术》
  • 课程：华为 HCIE-Datacom 数据中心专项、阿里云 ACP 云网络工程师课程

2. 云原生网络架构

核心学习内容

  1. 阿里云 VPC 核心原理（虚拟交换机、路由器、安全组、网络 ACL）
  2. 云上网络隔离与互通、VPC 对等连接、云企业网 CEN
  3. 混合云专线（Direct Connect）架构、IPsec VPN 云上云下互通方案
  4. 云负载均衡 SLB（四层）/ALB（七层）核心原理、转发策略、高可用设计
  5. 云上 NAT 网关、公网出口架构、云上高可用网络设计、云网络故障排障

必做实操项目

  1. 基于阿里云账号，搭建多 VPC 互通架构，完成安全组与网络 ACL 的精细化隔离设计
  2. 配置 SLB/ALB 实现业务的四层 / 七层负载分担、会话保持、健康检查，验证业务高可用
  3. 通过 IPsec VPN 实现线下模拟器环境与阿里云 VPC 的混合云互通，验证端到端流量走向

验收标准

  • 能结合 ECS 使用经验，独立完成云上 VPC 网络的规划与部署，理解云网络的全链路转发逻辑
  • 能独立设计混合云网络架构，实现线下 IDC 与云上资源的安全稳定互通
  • 能排查云上网络互通、负载均衡、安全隔离相关的典型故障

配套学习资源 / 工具

  • 工具：阿里云账号（免费试用 / 个人版）、阿里云 VPC / 负载均衡官方控制台
  • 文档：阿里云官方云网络产品文档、最佳实践手册
  • 课程：阿里云 ACP/ACE 云网络工程师认证课程
