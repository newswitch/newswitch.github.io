# 附录F：模型显存/HBM、设备、副本和故障容量计算表

:::info 系列与定位
**所属系列**：《NVIDIA＋昇腾双资源池 AI 推理集群：从 0 到部署、运维与故障排查》
**用途**：部署前估算、压测后修正、资源配额、扩容和双池容灾
**原则**：公式用于初算，生产结论必须由目标镜像、目标模型和真实请求压测确认
:::

:::tip 系列约定
资源池 A = **NVIDIA GPU**（vLLM）· 资源池 B = **华为昇腾 NPU**（vLLM-Ascend）· 同一 Kubernetes · 共享存储/网关/监控 · **禁止**跨池组成同一分布式模型实例。
:::

## 2. 权重内存初算 {/* #二权重内存初算 */}

```text
权重字节数 ≈ 参数量 × 每参数字节数
```

| 精度 | 理论字节/参数 | 说明 |
|------|---------------|------|
| FP32 | 4 | 推理较少使用 |
| FP16 / BF16 | 2 | 常见基础推理精度 |
| INT8 | 1 | 还存在 Scale / Zero Point 等开销 |
| INT4 | 0.5 | 实际格式、分组和 Metadata 会增加开销 |

示例：70B 模型 BF16 理论权重 ≈ `70e9 × 2 Byte ≈ 130.4 GiB`。

实际还要增加：量化元数据、Embedding/LM Head 处理方式、对齐和分片、运行时临时副本、反序列化缓冲。不要把模型目录文件大小直接等同于加载后设备内存。

|------|--------|------|
| 参数量 B | | |
| 权重格式 | | |
| 理论字节/参数 | | |
| 理论权重 GiB | | |
| 实测加载后权重 GiB | | |
| 格式/量化额外开销 | | |

## 4. KV Cache 初算 {/* #四kv-cache-初算 */}

对常见 Transformer，单 Token KV Cache 理论量级可近似为：

```text
单Token KV字节 ≈ 2 × 层数 × KV Head数量 × Head Dimension × KV元素字节
# 其中 2 代表 Key 和 Value

总KV字节 ≈ 单Token KV字节 × 所有并发序列已缓存Token总数
```

实际还受 GQA/MQA、TP 切分、KV 数据类型、Block 与 Metadata、Prefix Cache、滑动窗口、引擎实现差异、碎片影响。公式只判断数量级，最终以引擎启动日志、指标和 OOM 边界为准。

## 5. 上下文与并发不能分别规划 {/* #五上下文与并发不能分别规划 */}

```text
Total Cached Tokens ≈ C × Tavg
# C = 平均并发序列，Tavg = 平均已缓存Token
```

最大上下文 8192 不代表每个并发请求都能同时使用 8192。

| 场景 | 并发 | 输入 P95 | 输出 P95 | 每序列缓存 Token 估算 | 总缓存 Token | 是否满足 |
|------|------|----------|----------|----------------------|--------------|----------|
| 普通聊天 | | | | | | |
| 长文档 | | | | | | |
| 混合峰值 | | | | | | |

入口网关必须限制：最大请求体、最大上下文、最大输出 Token、单租户并发、Token 配额——否则后端容量假设会被单个超长请求打破。

## 7. 单副本吞吐基线 {/* #七单副本吞吐基线 */}

| 请求/s | | |

| OOM / 崩溃并发 | | |
| 舒适区利用率 | | |
| 功耗 | | |

「最大吞吐」≠「可售吞吐」。生产承诺应使用满足 SLO 且保留余量的稳定值：

```text
单副本可售容量 = 单副本稳定容量 × 安全系数
# 安全系数 < 1，例如 0.7～0.85，具体由业务波动、冷启动和可靠性目标决定
```

## 8. 副本数计算 {/* #八副本数计算 */}

```text
所需副本数 = ceil(峰值业务负载 ÷ 单副本可售容量)
# 请求/s 和 Token/s 都要算，取更高结果

平均并发 ≈ 请求到达率 × 平均服务时间   # Little's Law 初估；长流式会显著抬高并发

生产最低副本数 = max(吞吐需要副本数, 高可用最低副本数)
```

在线关键服务通常至少两个完整副本并跨节点 / 故障域。

## 12. HPA 上下限计算 {/* #十二hpa-上下限计算 */}

```text
minReplicas = max(HA最低副本, 基线流量需要副本)
maxReplicas <= 该模型设备配额 ÷ 单副本设备数

HPA可使用设备预算
= 资源池Healthy设备
- 其他模型承诺 - 发布预留 - 故障预留 - 平台机动容量
```
