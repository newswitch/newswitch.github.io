# 附录B：双资源池软硬件兼容矩阵模板

:::info 系列与定位
**所属系列**：《NVIDIA＋昇腾双资源池 AI 推理集群：从 0 到部署、运维与故障排查》  
**用途**：选型、安装、升级、发布和故障回滚  
**原则**：一行代表一个经过验证的完整组合，**不用「应该兼容」代替测试结果**
:::

:::tip 系列约定
资源池 A = **NVIDIA GPU**（vLLM）· 资源池 B = **华为昇腾 NPU**（vLLM-Ascend）· 同一 Kubernetes · 共享存储/网关/监控 · **禁止**跨池组成同一分布式模型实例。
:::

## 一、状态定义

| 状态 | 含义 | 是否允许生产使用 |
|------|------|------------------|
| Planned | 计划验证 | 否 |

## 十四、使用纪律

1. 兼容矩阵描述的是**已验证组合**，不是厂商全部理论支持范围。  
2. 任一关键组件版本变化，都要判断是否生成新 Matrix ID。  
3. 生产节点不得存在无法解释的版本漂移。  
4. NVIDIA 验证通过不能推导昇腾也通过，反之亦然。  
5. `latest` 镜像无法形成可审计矩阵。  
6. 回滚组合也必须提前验证。  
7. Deprecated 组合保留到所有回滚窗口结束后再 Retired。  
8. 每季度复核矩阵、实际节点和镜像 Digest 是否一致。
