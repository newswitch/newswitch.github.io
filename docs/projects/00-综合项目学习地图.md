# 综合项目学习地图

综合项目用于验证你能否把基础模块连接成完整系统。

## 三组项目

1. **端到端链路**：从 GPU Pod 提交、模型加载、单机训练、多机训练到联合拓扑调度。
2. **生产级 GPU 集群**：完成架构设计、部署、故障演练和学习总结。
3. **NVIDIA＋昇腾双资源池**：从裸机、Kubernetes、存储、推理部署到监控、容灾和验收。

建议先完成 `end-to-end/`，再做 `gpu-cluster/`，最后进入
[NVIDIA＋昇腾双资源池专栏](./heterogeneous-cluster/00-专栏目录.md)。

完成标准是能解释一次请求或训练任务从提交到结束经过的每个控制面与数据面，
并能为关键环节给出观测指标、容量假设、失败模式和排障步骤。
