# 配置发布、监听、灰度、加密、回滚与动态刷新

```text
CI/operator publish
→ Nacos persists content/version
→ listener notified/fetches
→ SDK local cache
→ application parses/validates/applies
→ effective-version metric
```

发布成功与全实例生效不同。应用可能因网络、Listener 异常、格式、刷新范围或旧 SDK 保留旧版本。

## 发布门禁

- Schema/语法/业务约束和 Secret 扫描；
- Diff、owner、审批、变更窗口；
- immutable revision/hash；
- 小实例/标签灰度；
- 应用有效版本、错误和业务 SLO；
- 自动停止和一键回滚。

## 动态刷新

并非所有参数适合热更新。线程池、数据库池、超时等需原子构建新对象、健康验证、切换和释放旧资源；端口/底层框架可能必须重启。配置类注明 reload policy。

## Secret

数据库密码/API Key 优先专用 Secret Manager；若通过 Nacos，使用加密插件/密文、最小权限、审计和轮换，日志/Console 禁止明文。

## 回滚

回滚发布旧内容的新 Revision，并同样灰度；数据库 Schema 等不可逆外部变化不能只回配置。保留 last-known-good 本地缓存和启动失败策略。
