# 平台工程学习地图

平台工程模块负责把服务器、GPU、网络与存储抽象成可声明、可调度、可观测的
集群资源。

| 模块 | 学习目标 | 入口 |
| --- | --- | --- |
| Kubernetes | 掌握控制面、Pod、网络、存储、安全、运维和扩展机制 | [Kubernetes 学习路线](./kubernetes/00-Kubernetes学习路线.md) |
| etcd | 掌握 Raft、MVCC、Revision、Watch、Lease、集群维护和灾难恢复 | [etcd 从零到精通](./etcd/00-etcd从零到精通学习路线.md) |
| ZooKeeper | 掌握 ZNode、Session、Watch、zxid、ZAB、集群部署与协调故障排查 | [ZooKeeper 从零到精通](./zookeeper/00-ZooKeeper从零到精通学习路线.md) |
| Nacos | 掌握服务发现、配置中心、Distro/Raft、客户端推送和集群部署 | [Nacos 从零到精通](./nacos/00-Nacos从零到精通学习路线.md) |
| Consul | 掌握 Agent、Gossip、Raft、DNS、健康检查、ACL 和混合基础设施服务发现 | [Consul 定位与学习路线](./consul/00-Consul定位与学习路线.md) |
| Istio 服务网格 | 掌握 Sidecar/Ambient、xDS、流量治理、mTLS、授权、Telemetry 和升级排障 | [Istio 从零到精通](./service-mesh/istio/00-Istio从零到精通学习路线.md) |
| GPU 集群 | 掌握设备发现、运行时、调度共享、DRA、治理和故障排查 | [Kubernetes GPU 集群学习路线](../gpu/cluster/00-Kubernetes-GPU集群学习路线.md) |
| KServe | 掌握模型服务控制面、Runtime、Gateway、LLM 路由、扩缩容和推理工作负载 | [KServe 从零到生产](../ai-systems/inference/kserve/00-KServe从零到生产学习路线.md) |
| Kubeflow Trainer | 掌握 TrainJob、Runtime、JobSet、分布式启动、队列准入和 Gang 调度 | [Kubeflow Trainer 从零到生产](../ai-systems/training/kubeflow-trainer/00-Kubeflow-Trainer从零到生产学习路线.md) |
| AI 多集群 | 掌握 GPU 资源目录、全局队列、模型数据分发、推理切流、训练唯一执行和容灾 | [AI 多集群技术学习路线](./kubernetes/multi-cluster/05-AI多集群技术学习路线.md) |
| 生态扩展 | 理解 Gateway API、LeaderWorkerSet 等 AI 原生扩展 | `kubernetes-extensions/` |

推荐先完成 Kubernetes 架构、Pod、调度、网络和存储章节，再进入 etcd、ZooKeeper 等分布式协调系统；理解 Service、EndpointSlice、CNI 和 Gateway API 后，再学习 Nacos/Consul 服务发现、Istio 服务网格和 GPU 集群。
学习过程中始终区分：**设备如何暴露给节点、资源如何发布给调度器、Pod 如何
获得设备、运行时如何把设备注入容器**。
