# Packer 性能、缓存与故障排查

## 1. 分层

| 阶段 | 常见问题 |
| --- | --- |
| Init | Plugin 来源、代理、证书、版本 |
| 创建资源 | IAM、配额、区域、镜像过滤 |
| Communicator | 网络、Host Key、用户、Cloud-init |
| Provisioner | 包锁、仓库、脚本非交互、重启 |
| 产出镜像 | 快照耗时、加密、标签、权限 |
| Cleanup | 异常中断、权限不足、残留资源 |

## 2. 证据

记录 Build ID、模板 Commit、Plugin、区域、基础镜像、临时资源和阶段耗时。Debug 日志可能含 Secret，按敏感资料处理。

## 3. 性能

优先优化大包下载、镜像启动、仓库延迟和重复 Provisioner。使用组织包镜像与可信缓存，缓存 Key 包含版本和平台，不能牺牲可重复性。

## 4. 并行

并行构建受云配额、网络和仓库限制。对不同平台并行，对同一共享资源加锁；故障时避免同时重试造成资源风暴。

## 5. 残留清理

按 Build 标签发现实例、盘、快照和安全组，先确认不属于活动构建，再走可审计清理。不能对模糊名称批量删除。
