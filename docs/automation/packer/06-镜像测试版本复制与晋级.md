# Packer 镜像测试、版本、复制与晋级

## 1. 测试层次

```text
模板 Validate
→ 镜像启动
→ Cloud-init/Agent
→ 服务和端口
→ 安全基线
→ 性能基线
→ Terraform 测试实例
```

## 2. 版本

镜像名称可读，镜像 ID 不可变。记录：基础镜像 ID、模板 Commit、Packer/Plugin、Provisioner 版本、补丁时间、SBOM 和测试。

## 3. 晋级

```text
构建账号生成候选
→ 测试账号验证
→ 安全审批
→ 复制到预生产/生产
→ 更新允许镜像目录
```

不要在每个环境重新运行构建，否则产物不再相同。

## 4. 跨区域/账号

复制后记录新 ID 与原产物关系，验证加密 Key、共享权限和区域功能。复制完成不等于所有快照可启动。

## 5. 回退

保留至少一个已验证旧镜像及其启动依赖。回退通常是创建新实例/节点池并迁移流量，不是修改运行中系统盘。

## 6. 生命周期

清理镜像前检查实例、启动模板、Auto Scaling、灾备和回滚引用。保留策略按引用而不是只按年龄删除。
