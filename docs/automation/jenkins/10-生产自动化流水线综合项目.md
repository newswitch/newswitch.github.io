# Jenkins 生产自动化流水线综合项目

## 1. 流程

```text
受保护 Git 分支
→ Lint/Unit/Secret Scan
→ 构建不可变制品
→ SBOM/漏洞扫描/签名
→ 测试环境
→ 人工与策略审批
→ Ansible 金丝雀
→ 分批生产
→ SLO 验收和证据归档
```

## 2. Agent 分池

- 外部 PR：无 Secret、无内网。
- 可信构建：可写测试制品库。
- 发布：只读取已签名制品，使用短期部署身份。

## 3. Pipeline 原则

Jenkinsfile 只编排，测试/构建/部署逻辑在版本化工具中。Stage 有 Timeout，生产环境有锁，旧构建不能越过新构建。

## 4. 制品

一次构建，多环境晋级。记录 Commit、Jenkins Build、镜像 Digest、SBOM、签名、审批和 Ansible Job ID。

## 5. 失败

测试失败不产生候选；发布超时先查询实际版本；金丝雀失败停止新批次；回滚同样需要验收。未知状态升级人工，不盲重试。

## 6. 验收

- [ ] 不可信代码无法读取生产凭据。
- [ ] Controller 不执行构建。
- [ ] 发布环境锁和失败阈值有效。
- [ ] 制品不可变且可验证。
- [ ] Controller/Agent 重启和恢复演练通过。
- [ ] 任一生产版本可追溯全部证据。
