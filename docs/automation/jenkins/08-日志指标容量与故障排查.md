# Jenkins 日志、指标、容量与故障排查

## 1. 关键指标

- Queue 长度、等待时间和最老任务。
- Agent 在线率、Provision 时间、Executor 使用率。
- Controller Heap、GC、线程、磁盘和响应时间。
- 构建成功率、时长、取消、重试和按阶段耗时。
- Webhook、SCM、制品仓库和部署 API 错误。

## 2. 分层排查

```text
Trigger
→ Queue 原因
→ Label/Executor/Agent
→ Checkout/Credential
→ Pipeline Step
→ Artifact/Test
→ Approval/Deploy
→ Post/Cleanup
```

## 3. Queue 等待

查看无匹配 Label、Agent 离线、并发限制、锁、静默期和上游依赖。单纯增加 Executor 可能压垮共享服务。

## 4. Controller

慢 UI 和调度可能来自 Heap/GC、插件、磁盘、过大日志、过多 Job/构建记录。收集线程转储和支持包时脱敏。

## 5. Agent

区分调度失败、镜像拉取、连接、工具缺失、磁盘满和 OOM。动态 Pod 消失后保留 Kubernetes 事件和容器日志。

## 6. 容量

用到达率、平均执行时间、峰值、资源规格和下游配额计算，不以 CPU 空闲单指标扩容。Queue SLO 比“有多少 Agent”更接近用户体验。
