# Temporal 测试、时间跳跃与故障注入

## 1. 测试金字塔

| 层 | 目标 |
| --- | --- |
| 纯函数测试 | 业务判断、状态转换、参数校验 |
| Workflow 测试环境 | Timer、Signal、重试、分支、补偿 |
| Activity 单元/契约 | 下游 API、幂等、错误分类 |
| Replay Test | 新代码兼容历史 |
| 集成/故障测试 | 真实 Service、Worker、数据库和网络 |

## 2. 时间跳跃

测试环境可跳过没有工作执行的长 Timer，让“等待 30 天”在短时间验证。仍要测试多个 Timer、Signal 在等待期间到达、取消和 Continue-As-New 边界。

## 3. Activity Mock

Mock 返回成功、可重试错误、不可重试错误、超时和未知结果。断言 Activity 参数和调用次数，但避免测试过度绑定内部拆分，使安全重构困难。

## 4. Replay Test

从生产导出脱敏 History，交给新 Workflow 代码 Replay。覆盖长时间运行、不同版本、Signal/Update、Timer 和异常路径。Replay 成功是部署门禁之一。

## 5. 故障注入

- Worker 在 Activity 完成前后崩溃；
- Activity 成功但完成响应丢失；
- Temporal Service 短时不可达；
- 下游 429/500/超时；
- Signal 重复、乱序和晚到；
- Worker 滚动升级；
- History 接近限制；
- Payload Codec/KMS 暂时不可用。

## 6. 断言最终状态

不仅断言 Workflow Completed，还验证外部副作用次数、补偿、业务幂等记录、Search Attribute、错误分类和审计。测试结束清理外部资源但保留失败证据。

## 7. 生产合成测试

在隔离 Namespace 周期运行无破坏的短 Workflow，验证启动、Task Queue、Worker、Activity、Signal、可见性和告警链。不能用真实生产变更作为健康检查。
