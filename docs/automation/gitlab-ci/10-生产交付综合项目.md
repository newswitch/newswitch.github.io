# GitLab CI 生产交付综合项目

## 1. 流程

```text
Merge Request
→ 测试/安全/Plan
→ 合并保护主分支
→ 构建镜像并推送 Harbor
→ SBOM/扫描/签名
→ 测试环境
→ 生产审批
→ 更新 GitOps 仓库 Digest
→ Argo CD 同步
→ SLO 验收
```

## 2. Runner

不可信 MR、构建、IaC Plan 和生产发布使用不同 Runner Pool 与身份。生产发布 Job 只消费已验证 Digest。

## 3. DAG

测试并行，构建依赖全部必需检查；安全报告和制品元数据作为 Artifact；部署依赖签名验证和保护环境审批。

## 4. IaC 与配置

Terraform Plan 使用只读/规划权限，Apply 独立身份；Ansible 负责主机配置；Argo CD 管理 Kubernetes 应用，所有权不重叠。

## 5. 失败

旧 Pipeline 无法部署覆盖新版本；发布超时查询实际 Digest；金丝雀失败停止；回滚提交同样经过保护流程。

## 6. 验收

- [ ] Fork 无生产 Secret/网络。
- [ ] Cache 污染不影响制品可信性。
- [ ] 一次构建多环境晋级。
- [ ] 环境发布串行且可取消旧任务。
- [ ] Commit、Pipeline、Runner、Digest、审批和部署可关联。
