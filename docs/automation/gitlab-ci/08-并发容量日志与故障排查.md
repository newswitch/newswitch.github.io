# GitLab CI 并发、容量、日志与故障排查

## 1. 指标

- Pipeline 创建/完成率、成功率和关键路径。
- Pending 时间、最老 Job、Runner 在线和并发。
- Executor 启动、镜像拉取、OOM 和磁盘。
- Artifact/Cache 上传下载和对象存储错误。
- SCM、Registry、Kubernetes 和部署 API 延迟。

## 2. Pending

检查 Runner Scope/Tag、保护分支匹配、Runner Paused/Offline、并发上限和平台配额。

## 3. Job 失败

```text
配置创建
→ Runner 获取
→ Executor 准备
→ 源码拉取
→ Cache/Artifact
→ Script
→ Upload/Cleanup
```

区分脚本非零、系统故障、超时、取消和 Runner 丢失。

## 4. 容量

按到达率、平均 Job 时间、峰值、资源规格和下游配额规划。增加 Runner 可能压垮 Registry 和 API。

## 5. 重试

只对 Runner/System/网络等明确瞬时故障有限重试。发布 Job 超时后先查询目标实际版本。

## 6. 日志

启用调试前评估 Token 和变量泄漏；收集 Runner 与 Kubernetes 事件时脱敏。保留 Job ID、Runner ID、Pod、Commit 和时间线。
