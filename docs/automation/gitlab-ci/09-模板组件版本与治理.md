# GitLab CI 模板、组件、版本与治理

## 1. 目标

平台团队提供测试、构建、扫描和部署能力，业务仓库只声明有限输入。模板不能隐藏风险和目标。

## 2. 接口

输入有类型/枚举/默认值和说明，输出 Artifact/报告有 Schema。高风险参数不允许任意 Shell 回调绕过。

## 3. 版本

Include/组件固定 Tag 或不可变版本；新版本通过示例项目和真实 Runner 回归。保留迁移期，记录破坏性变化。

## 4. 治理

- 模板仓库受保护。
- 发布版本签名和 Changelog。
- 项目采用率、失败率和升级滞后可观测。
- 弃用有期限和自动检测。

## 5. Golden Path

提供安全默认值，但允许受控扩展。特殊需求通过明确 Escape Hatch 和审批，而不是复制整套模板后永久分叉。
