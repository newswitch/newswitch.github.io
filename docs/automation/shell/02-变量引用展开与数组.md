# Shell 变量、引用、展开与数组

大量 Shell 故障不是命令失败，而是数据在到达命令前被 Shell 重新切分或展开。安全脚本的核心原则是：一个逻辑参数始终作为一个参数传递。

## 1. 变量没有默认的数据边界

```bash
file='report final.txt'
printf '<%s>\n' $file
printf '<%s>\n' "$file"
```

未引用展开可能发生单词分割和路径名展开；双引号通常保留一个参数边界。

推荐：

```bash
rm -- "$file"
printf '%s\n' "$value"
```

`--` 可以阻止支持该约定的命令把以 `-` 开头的文件名解释为选项，但仍需查阅具体命令接口。

## 2. 常用参数展开

```bash
${name:-default}   # 未设置或为空时使用默认值
${name:=default}   # 未设置或为空时赋默认值
${name:?message}   # 未设置或为空时失败
${name:+alternate} # 已设置且非空时使用替代值
```

严格要求配置：

```bash
: "${API_ENDPOINT:?API_ENDPOINT is required}"
```

区分未设置与空字符串时，不要机械使用带冒号形式，要根据接口语义选择。

## 3. 命令替换

```bash
current_commit=$(git rev-parse HEAD)
```

命令替换会移除尾部换行，不能无损保存任意二进制数据，也不能仅凭结果判断命令是否成功：

```bash
if ! current_commit=$(git rev-parse HEAD); then
  printf 'cannot resolve HEAD\n' >&2
  exit 3
fi
```

如果在 `local value=$(command)` 中依赖退出状态，声明命令可能掩盖命令替换的状态。分开写：

```bash
local value
value=$(command)
```

## 4. 数组保存参数列表

错误做法：

```bash
options='--header X-Name: demo --retry 3'
curl $options "$url"
```

正确使用 Bash 数组：

```bash
options=(
  --header 'X-Name: demo'
  --retry 3
)
curl "${options[@]}" "$url"
```

`"${array[@]}"` 保留每个元素为独立参数；`"${array[*]}"` 通常连接为一个参数，语义不同。

## 5. 读取行和 NUL 分隔数据

读取文本行：

```bash
while IFS= read -r line; do
  printf '%s\n' "$line"
done < input.txt
```

文件名可以包含空格、Tab 和换行。跨工具传递文件列表时使用 NUL 分隔：

```bash
while IFS= read -r -d '' path; do
  printf '%q\n' "$path"
done < <(find . -type f -print0)
```

或使用支持 NUL 输入的工具接口，避免通过 `for path in $(find ...)` 解析输出。

## 6. 通配符与空匹配

```bash
files=(/var/log/app/*.log)
```

在 Bash 默认行为下，模式无匹配时可能保留字面模式。可在局部明确使用 `nullglob`，但要理解它会改变整个当前 Shell 的展开行为：

```bash
shopt -s nullglob
files=(/var/log/app/*.log)
shopt -u nullglob
```

更稳妥的复杂文件遍历通常使用 `find ... -print0`。

## 7. 整数与算术

```bash
declare -i retries=3
(( retries > 0 )) || exit 2
```

不要把未经校验的外部字符串直接放入算术表达式或数组下标。先使用格式校验：

```bash
[[ $input =~ ^[0-9]+$ ]] || exit 2
```

## 8. 引用检查清单

- [ ] 路径、URL、用户输入和命令结果均使用双引号。
- [ ] 参数列表使用数组，不用字符串拼命令。
- [ ] 文件名列表使用 NUL 分隔。
- [ ] 需要通配符时明确空匹配行为。
- [ ] 不用 `eval` 解析参数字符串。
- [ ] 命令替换同时检查退出状态。
