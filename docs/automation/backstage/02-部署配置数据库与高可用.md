# Backstage 部署、配置、数据库与高可用

## 1. 环境路径

```text
本地开发：单进程 + 开发配置
预生产：真实 IdP/数据库/外部集成的隔离环境
生产：多副本 Backend + 外部 PostgreSQL + TLS + 观测与备份
```

模板仓库或示例配置不能直接作为生产安全基线。

## 2. 构建与配置

前后端依赖锁定，生成 SBOM、扫描并发布不可变镜像 Digest。配置按基础、环境和 Secret 分层；非敏感配置进入 Git，Secret 通过 Vault/External Secrets 注入。前端可见的配置不能包含私密值。

## 3. PostgreSQL

生产使用受支持的外部 PostgreSQL，规划连接池、备份、恢复、升级和插件数据库迁移。多副本 Backend 共享数据库；本地文件数据库不适合多副本生产。

升级前在生产数据副本演练迁移。数据库已向前迁移后，回滚不能只替换旧镜像。

## 4. Kubernetes 部署

- 多副本、反亲和、PDB 和滚动更新；
- Readiness 验证关键依赖，Liveness 不因短时外部 API 失败重启；
- CPU/内存 Request 和限制基于压测；
- NetworkPolicy 只允许数据库、IdP、Git 和必要集成；
- Ingress TLS、可信代理头和外部 URL 一致；
- 后台任务明确单实例/分片/锁语义，避免多副本重复执行。

## 5. 高可用边界

Backend 多副本不代表 PostgreSQL、对象存储、IdP、Git Provider 和搜索后端高可用。为关键依赖定义超时、缓存、降级页面和 SLO。

## 6. 备份与恢复

备份数据库、配置、插件版本、TechDocs 存储、搜索重建信息和外部集成设置。目录实体如果来自 Git/Provider，可重建，但仍要验证恢复时间和关系一致性。
