# AI 训练数据面从零到生产学习路线

训练数据面负责持续把足够的数据送到加速器，并把 Checkpoint 安全写出。GPU 利用率低不一定是算力不足，也可能是样本没有及时到达。

```text
对象存储/并行文件系统
→ Dataset Shard与元数据
→ 节点缓存/页缓存
→ DataLoader Worker
→ Decode/Transform/Collate
→ Pinned Memory
→ H2D DMA
→ GPU Forward/Backward
→ Checkpoint反向写回
```

## 2. 核心指标

| 指标 | 说明 |
| --- | --- |
| Samples/s、Tokens/s | 训练实际消费速率 |
| Data Wait/Step | 每个 Step 等待数据的时间 |
| Cache Hit Ratio | 本地/分布式缓存命中率 |
| Read BW/IOPS/P99 | 数据读取吞吐与尾延迟 |
| Metadata Ops/s | Open、Stat、List 等元数据压力 |
| H2D BW | 主机到设备搬运效率 |
| Checkpoint Duration | 保存窗口和恢复点间隔 |
| Storage Goodput | 有效样本/Checkpoint 字节占总 I/O 的比例 |

## 3. 完成标准

- 能从 GPU Bubble 追到 DataLoader、缓存、文件系统或对象存储；
- 能根据访问模式选择 Shard 大小和文件格式；
- 能解释 Worker 数、预取、Pinned Memory 和 NUMA 的边界；
- 能比较 Lustre、BeeGFS、JuiceFS、Alluxio/Fluid 与本地缓存；
- 能避免千卡任务同时回源或同时写 Checkpoint；
- 能构造真实数据分布的基准并用时间线证明瓶颈。

参考：[PyTorch DataLoader](https://docs.pytorch.org/docs/stable/data.html)、[PyTorch Distributed Checkpoint](https://docs.pytorch.org/docs/stable/distributed.checkpoint.html)。
