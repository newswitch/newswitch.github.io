# 第二阶段：数据中心与云网络学习路线

## 1. 阶段目标 {/* #阶段目标 */}

从“会配置路由协议”升级为“能够设计和排查现代数据中心 Fabric”。学习时始终把
网络拆成三个互相独立又互相依赖的平面：

```text
Underlay：VTEP 的 IP 是否可达
Overlay 控制面：MAC、IP、前缀是否被正确发布和导入
Overlay 数据面：VXLAN 是否按正确 VNI 封装并沿 ECMP 路径转发
```

## 2. 学习顺序 {/* #学习顺序 */}

1. [Clos 与 Spine-Leaf 架构](./01-Clos与Spine-Leaf数据中心架构.md)
2. [Underlay 的 eBGP、OSPF、ECMP 与 BFD](./02-Underlay路由设计与收敛.md)
3. [VXLAN 数据面与 VTEP/VNI](./03-VXLAN数据面与隧道实验.md)
4. [BGP EVPN 控制面与路由类型](./04-BGP-EVPN控制面与路由类型.md)
5. [Anycast Gateway、IRB、BUM 与多归属](./05-EVPN网关BUM与多归属.md)
6. [云 VPC、路由、安全、NAT 与负载均衡](./06-云VPC网络与全链路分析.md)
7. [混合云、专线、VPN 与路由边界](./07-混合云互联与路由设计.md)
8. [GTM 全局调度与故障切换](../load-balancing-proxy/08-GTM实现跨网访问加速与故障切换.md)
9. [VXLAN/EVPN 分层排障](../troubleshooting/09-VXLAN-EVPN故障排查.md)
10. [综合项目：2 Spine + 4 Leaf Fabric](../labs/10-数据中心Fabric综合项目.md)

理论阅读时先跟踪同子网 VXLAN 帧，再读 EVPN 的路由对象与安装依赖，最后进入跨子网 IRB 和多归属。这样可以区分“谁告诉设备远端在哪里”“本次封装携带什么”和“哪台设备有资格向接入段交付”。

Underlay 的另一条 IGP 主线见 [IS-IS](../routing-switching/12-IS-IS层次邻接泛洪与SPF.md)；路径约束与保护见 [Segment Routing](../routing-switching/13-Segment-Routing-SR-MPLS与SRv6.md)；路径正确但时延超标时，继续进入 [QoS 与拥塞](../automation/08-QoS流量工程.md)。

## 3. 阶段验收 {/* #阶段验收 */}

- 能说明为什么 Leaf-Spine 通过 ECMP 提供水平扩展，而不是只会画拓扑图。
- 能从外层/内层报文解释 VXLAN 封装、VTEP、VNI 和 MTU 开销。
- 能区分 EVPN Type 2、Type 3、Type 5 路由分别解决的问题。
- 能逐跳说明对称/非对称 IRB 的 MAC、TTL 与 VNI 变化，并区分 DF 与 Split Horizon。
- 能根据路由表、EVPN RIB、FDB、ARP/ND、VNI 和抓包定位故障层级。
- 能把云厂商的 VPC、路由表、安全组、NAT 网关映射到通用网络原理。
