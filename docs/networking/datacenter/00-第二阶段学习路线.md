# 第二阶段：数据中心与云网络学习路线

## 阶段目标

从“会配置路由协议”升级为“能够设计和排查现代数据中心 Fabric”。学习时始终把
网络拆成三个互相独立又互相依赖的平面：

```text
Underlay：VTEP 的 IP 是否可达
Overlay 控制面：MAC、IP、前缀是否被正确发布和导入
Overlay 数据面：VXLAN 是否按正确 VNI 封装并沿 ECMP 路径转发
```

## 阶段验收

- 能说明为什么 Leaf-Spine 通过 ECMP 提供水平扩展，而不是只会画拓扑图。
- 能从外层/内层报文解释 VXLAN 封装、VTEP、VNI 和 MTU 开销。
- 能区分 EVPN Type 2、Type 3、Type 5 路由分别解决的问题。
- 能根据路由表、EVPN RIB、FDB、ARP/ND、VNI 和抓包定位故障层级。
- 能把云厂商的 VPC、路由表、安全组、NAT 网关映射到通用网络原理。
