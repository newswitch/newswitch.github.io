# 负载均衡、重试、超时、熔断、健康与流量灰度

## 预算

```text
client deadline
> gateway route timeout
> per-try timeout
> upstream internal timeout
```

重试次数 × per-try 必须落在总预算内，且留网络/排队时间。网关、Sidecar、SDK、应用不能各自重试多次。

## LB/健康

Round-robin、least request、ring hash 等按连接/请求/Key交换。主动健康发现不可用，Outlier Detection 按连续失败/成功率临时驱逐；过敏参数会在短故障中驱逐所有 Endpoint。

## Circuit Breaker

限制连接、Pending、请求和重试，保护 Gateway/上游；触发返回 503 等并应区分 no healthy upstream。它不替代业务降级和全局限流。

## 灰度

按 Header/Cookie/用户 hash/权重路由，标识必须可信且稳定。灰度同时控制配置、Endpoint、插件和镜像版本；比较同窗口错误/P99/业务指标并自动回滚。

## 幂等

只有幂等且未输出响应的请求适合自动重试；LLM Streaming 已输出 token 后不能换后端无缝重试。携带 request/attempt ID。
