# WLAN 与无线网络学习路线

手机显示无线信号满格，只说明它测得的接收信号较强，不保证信道空闲、认证成功、地址可用或应用快速响应。学习 WLAN，需要分别理解空口、接入系统和端到端业务。

## 2. 将无线放回完整网络

```text
射频传播与共享信道
    ↓ 承载无线帧
STA ↔ AP：发现、关联、接入安全与数据传输
    ↓ 根据转发模式交付
本地业务 VLAN，或经隧道到集中转发设备
    ↓
地址配置 → 名称解析 → 网关／安全策略 → 应用

AP／AC 的管理与认证路径在旁路支撑上述过程，
不代表每个用户业务包都经过管理服务器。
```

射频解决“帧能不能有效传递”；认证决定“谁被允许进入”；转发决定“包送到哪里”；漫游还要求这些状态在接入点变化后继续匹配。

空口时间公平不等于字节公平，关联完成不等于业务恢复，IP 组播也不等于每一段无线传输都使用组密钥。这三个边界分别对应资源、状态和封装，适合在阅读中反复对照。
