# DHCP 学习路线

DHCP 的核心不是“给电脑发一个 IP”，而是让客户端与服务器在有限时间内，对一组网络配置的使用权达成一致。

## 1. 阅读顺序

1. [DHCPv4 地址分配、DORA 与租约状态机](./01-DHCPv4地址分配DORA与租约状态机.md)：从一台没有地址的主机开始，理解发现、选择、续租、重绑定和失效。
2. [DHCP Relay、地址池选择与高可用](./02-DHCP-Relay地址池选择与高可用.md)：从多个 VLAN 共用一组服务器开始，理解中继信息、地址归属和状态协调。
3. [SLAAC 与 DHCPv6 地址分配机制](../../fundamentals/ipv6/04-SLAAC与DHCPv6地址分配机制.md)：对照 IPv6 的 DUID、IA、前缀委派与 RA 分工。

## 2. 用哪些对象理解 DHCP

| 对象 | 需要掌握的关系 |
| --- | --- |
| 客户端身份 | 不一定只等于网卡 MAC，标识变化会影响租约识别 |
| 子网与地址池 | 地址属于哪个网络，与从哪个候选集合分配是两件事 |
| 租约 | 包含客户端、地址、期限和状态，不只是一个地址字符串 |
| 中继 | 将客户端所在链路的信息交给远端服务器 |
| 高可用伙伴 | 既要处理请求，也要避免对同一资源作出冲突承诺 |
| IPAM | 管理地址意图和归属，不自动等同于实时租约数据库 |

DHCP 原理掌握后，再阅读具体产品的部署和配置文档，才容易判断差异是协议要求、实现策略，还是本地管理约定。
