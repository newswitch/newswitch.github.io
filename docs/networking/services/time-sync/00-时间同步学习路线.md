# NTP 与 PTP 时间同步学习路线

把时间显示为同一个时区，只改变显示方式；让不同机器在规定误差内理解同一时刻，才是时间同步。

## 1. 阅读顺序

1. [NTP、时钟偏差与时间误差预算](./01-NTP时钟偏差与时间误差预算.md)：理解四时间戳估计、偏差与漂移、选源、步进与渐进校时、NTS。
2. [PTP、硬件时间戳与 PHC 时钟体系](./02-PTP硬件时间戳与PHC时钟体系.md)：理解 Sync 消息、硬件测量位置、时钟角色、Profile，以及网卡时钟到系统时钟的同步链。

## 2. 先区分要达到的目标

| 目标 | 关注点 |
| --- | --- |
| 时间戳接近共同参考 | 时间／相位偏差及其不确定性 |
| 两个时钟走得一样快 | 频率误差和长期漂移 |
| 测量本机任务耗时 | 合适的单调时钟，不依赖墙上时间是否跳变 |
| 比较跨机器事件 | 各机器误差范围、时间尺度以及事件关联信息 |

NTP/PTP 可以降低时间误差，但不能把跨机器时间戳变成绝对可靠的事件因果排序，更不能替代共识协议或事务机制。
