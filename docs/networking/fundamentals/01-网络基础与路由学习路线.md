# 第一阶段：网络基础与路由学习路线

## 1. 阶段目标 {/* #阶段目标 */}

第一阶段只解决一件事：**彻底掌握一个数据包在主机、交换机、路由器和中间设备中
如何被封装、查表、转发、过滤和改写**。

不要从 BGP 选路规则开始背。正确顺序是：

3. [以太网、MAC、ARP、VLAN 与 Linux Bridge](../routing-switching/03-以太网ARP与VLAN.md)
4. [二层环路、STP 与链路聚合](../routing-switching/04-STP与链路聚合.md)
5. [ICMP、UDP、TCP、DNS 与连接诊断](./04-ICMP-UDP-TCP与DNS.md)

## 2. 每学完一篇都要回答 {/* #每学完一篇都要回答 */}

- 包进入这一层时是什么格式，离开时改变了什么？
- 设备依据哪张表做决定？这张表由谁生成？
- 成功状态能用什么命令证明？
- 失败时最小可证伪假设是什么？
- 重启为什么可能暂时恢复，又可能删除哪些证据？

## 3. 阶段验收 {/* #阶段验收 */}

完成综合项目后，你应该可以只根据以下五类证据定位大多数基础网络故障：

```text
配置意图
接口与链路状态
控制面邻居和路由
数据面表项与计数器
端到端报文与应用结果
```
