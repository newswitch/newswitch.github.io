# 网络技术学习路线

网络知识由协议、转发、基础服务和具体组网技术共同组成。先理解数据包如何到达目的地，
再理解终端如何获得配置、应用如何找到服务，以及主机与交换网络怎样支撑不同负载。

## 1. 推荐顺序 {/* #推荐顺序 */}

1. [**传统网络从零到精通**](./fundamentals/00-传统网络从零到精通学习路线.md)：
   从数据包、二三层和路由，逐步进入 Clos、VXLAN/EVPN、云网络与安全自动化。
2. [**IPv6 与双栈网络**](./fundamentals/ipv6/00-IPv6学习路线.md)：
   从报文与地址进入 NDP、RA、SLAAC、DHCPv6、路径 MTU 和双栈连接选择。
3. [**网络服务**](./services/00-网络服务学习路线.md)：
   分别学习 [DHCP](./services/dhcp/00-DHCP学习路线.md) 的租约与中继、[DNS](./services/dns/00-DNS学习路线.md) 的解析与缓存，以及 [NTP/PTP](./services/time-sync/00-时间同步学习路线.md) 的时间测量与误差。
4. [**VRRP 与网关冗余**](./routing-switching/vrrp/00-VRRP学习路线.md)：
   理解虚拟 IP/MAC、通告与选举、抢占、收敛、双主，以及网关切换与会话连续性的区别。
5. [**IGMP、PIM 与组播**](./routing-switching/multicast/00-组播学习路线.md)：
   从成员关系进入共享树、源树、RPF、Snooping 和 Querier，区分二层复制与三层组播路由。
6. [**网络安全与 VPN**](./security/00-网络安全学习路线.md)：
   分别学习 ACL/NAT、AAA/802.1X、二层接入保护与 IPsec，理解身份、策略、地址绑定和加密边界。
7. [**WLAN 与无线网络**](./wireless/00-WLAN学习路线.md)：
   从射频与空口容量进入 AP/AC、CAPWAP、无线接入安全及 802.11r/k/v 漫游。
8. [**网络命令参考库**](./commands/00-网络命令参考库学习路线.md)：
   先用 `nmcli/networkctl` 确认配置所有权，用 `ip`、`ss`、`bridge`、`tc`、`tcpdump` 和 `ethtool` 验证本机对象，再用 `arping/lldpcli` 核对二层邻居与交换机端口；通过 `ping`、`traceroute/mtr`、`dig/resolvectl`、`nc`、`curl`、`openssl s_client` 和 `iperf3` 完成路径、DNS、端口、TLS 与性能诊断；最后用防火墙/连接跟踪工具和 `rdma`/verbs/GID/perftest 定位策略、状态和高速数据面问题。
9. [**Linux 高性能网络**](./high-performance/01-linux高性能网络详解读书笔记（一）.md)：
   理解内核收包、软中断、队列、DPDK 与零拷贝。
10. [**RDMA**](./rdma-roce/01-RDMA技术详解（一）：RDMA概述.md)：
   掌握 Queue Pair、Memory Region、Send/Receive、RDMA Read/Write。
11. [**AI 集群网络从零到精通**](./ai-fabric/00-AI集群网络从零到精通学习路线.md)：
   学习训练通信、InfiniBand/RoCE、GPUDirect、无损 Fabric、Multi-Rail 和 Kubernetes RDMA。
12. [**NVSHMEM**](./rdma-roce/ai-cluster/11-NVSHMEM与GPU-One-Sided通信模型.md)与[**UCX/UCC/SHARP**](./rdma-roce/ai-cluster/12-UCX-UCC-SHARP与集合通信卸载.md)：
   继续学习 GPU 发起 One-Sided 通信、统一通信抽象和网络内 Collective 卸载。
13. [**BlueField DPU 与 DOCA**](./dpu/00-BlueField-DPU-DOCA与AI基础设施卸载.md)：
   理解网络、存储、安全和基础设施 Agent 如何从 Host 卸载到 DPU。
14. [**Nginx**](./load-balancing-proxy/nginx/00-Nginx从零到精通学习路线.md)：
   从反向代理进入 Master/Worker、事件循环、HTTP 阶段、TLS、缓存、性能和源码。
15. [**Envoy**](./load-balancing-proxy/envoy/00-Envoy从零到精通学习路线.md)：
   掌握 Listener、Filter、Route、Cluster、Endpoint、xDS 与动态代理数据面。
16. [**Higress**](./load-balancing-proxy/higress/00-Higress从零到精通学习路线.md)：
   在 Envoy 基础上学习 Gateway API、Nacos 服务发现、Wasm 与 AI Gateway。
17. [**Apache APISIX**](./load-balancing-proxy/apisix/00-APISIX定位与学习路线.md)：
   学习 Nginx/Lua 数据面、etcd 动态配置、Route/Upstream、插件、认证和网关故障排查。
18. [**HAProxy**](./load-balancing-proxy/haproxy/00-HAProxy定位与学习路线.md)：
   学习 L4/L7 负载均衡、ACL、健康检查、连接队列、Runtime API 和安全 Reload。
19. [**网络故障排查案例**](./troubleshooting/11-跨运营商延迟300ms故障排查复盘.md)：
   从跨运营商访问延迟与丢包案例学习用户侧拨测、应用分段计时、MTR 证据边界、双向路径验证和多入口应急。

## 2. 路由交换与广域网的理论主线 {/* #核心协议理论主线 */}

理解 MAC、IP 和路由后，可以按下列问题继续推导协议，而不是只记命令结果：

| 模块 | 阅读中需要建立的因果关系 |
| --- | --- |
| [STP、LACP 与 MLAG](./routing-switching/04-STP与链路聚合.md) | 二层环路 → BPDU 比较与端口状态 → 聚合成员资格 → 跨设备协同与分区边界 |
| [OSPF、ECMP 与 BFD](./routing-switching/06-OSPF-ECMP与BFD.md) | 报文与邻接 → LSA/LSDB → SPF/区域边界 → RIB/FIB → 检测与收敛 |
| [IS-IS](./routing-switching/12-IS-IS层次邻接泛洪与SPF.md) | NET/系统身份 → L1/L2 邻接 → DIS 与 LSP 同步 → SPF/跨层路由 → IPv6 拓扑 |
| [BGP](./routing-switching/07-BGP原理策略与双出口实验.md) | 会话与地址族 → 候选和策略 → 下一跳递归 → RR 传播 → 入口、出口与安全边界 |
| [MPLS L3VPN](./routing-switching/09-MPLS-VRF与L3VPN.md) | VRF 上下文 → RD/RT 与 VPN 路由 → 传输标签/业务标签 → 逐跳交付 |
| [Segment Routing](./routing-switching/13-Segment-Routing-SR-MPLS与SRv6.md) | SID 指令 → SR-MPLS 标签/SRv6 行为 → SR Policy 与流量导入 → 路径约束与保护 |
| [VXLAN 数据面](./datacenter/03-VXLAN数据面与隧道实验.md) | 接入广播域 → MAC 位置 → VTEP/承载邻居 → 内外层报文 → BUM/MTU |
| [EVPN 控制面](./datacenter/04-BGP-EVPN控制面与路由类型.md)与 [IRB/多归属](./datacenter/05-EVPN网关BUM与多归属.md) | 路由对象与依赖 → 服务导入 → 逐跳 MAC/VNI 变化 → DF/防回送与成组收敛 |
| [QoS 与拥塞](./automation/08-QoS流量工程.md) | 突发与积压 → 标记/计量 → 排队/调度 → AQM/ECN → 发送端反馈 |
| [SD-WAN](./automation/09-SD-WAN架构与排障.md) | Underlay/Overlay → 路由与分段 → 应用分类/SLA → 有效路径选择 → 会话连续性 |

每条主线都应能解释正常运行，也能解释“邻居已建立、路由已存在、隧道已上线，但业务仍失败”的中间状态。协议概念、厂商扩展和实际测量结果需要分别判断。

## 3. 学习边界 {/* #学习边界 */}

传统网络主线负责建立通用转发、路由、Fabric、云互联、QoS 和自动化能力；
IPv6 系列补充另一套地址、邻居与自动配置机制；网络服务解释地址租约、名称缓存和时钟同步怎样为业务提供基础状态；
VRRP 与组播分别解释入口接管和按需复制；网络安全区分身份、策略与加密；WLAN 将这些机制放到共享空口与移动接入场景中；
网络命令参考库负责把概念落实为可观察、可变更和可验证的内核对象，并建立从本机状态到端到端服务质量的证据链；
Linux 高性能网络继续进入主机协议栈和网卡队列；RDMA 与 AI 集群网络再研究
内核旁路、无损以太网、集合通信和 GPU Direct。先分层掌握，再在综合项目中串联，
排障时才不会把所有丢包都笼统归因于“网络不稳定”。

完成后继续阅读[GPU 网卡存储联合拓扑调度](../projects/ai-infra-end-to-end/05-GPU网卡存储联合拓扑调度.md)，
将网络拓扑与 Kubernetes 调度联系起来。
