# 二层接入安全学习路线

以太网中，终端发出一个源 MAC、ARP 声明或路由通告，并不自动证明它有权使用该身份或承担该角色。二层接入保护把这些声明与端口、租约和拓扑角色联系起来。

## 1. 阅读顺序

1. [地址绑定、DHCP Snooping、DAI 与 IPv6 接入保护](./01-地址绑定DHCP-Snooping-DAI与IPv6接入保护.md)：区分 MAC、ARP 与绑定表，理解报文字段检查、状态恢复和 IPv6 多地址模型。
2. [生成树保护、风暴控制与端口隔离](./02-生成树保护风暴控制与端口隔离.md)：追踪 Guard 触发与恢复，计算不同限速口径，再用 PVLAN 交付矩阵理解隔离范围。

## 2. 两类信任边界

| 边界 | 关键问题 |
| --- | --- |
| 身份和地址 | 这个端口是否有权声称使用这个 IP/MAC 或发布网关信息 |
| 交换拓扑 | 这个端口是否应该连接交换设备、宣告根桥或承载多个终端 |

先掌握 [DHCP](../../services/dhcp/00-DHCP学习路线.md)、[NDP/RA](../../fundamentals/ipv6/03-NDP邻居发现与RA路由通告.md) 和 [STP](../../routing-switching/04-STP与链路聚合.md)，再理解安全功能依赖的正常行为。

身份通过认证不等于任意地址声明都合法；二层地址合法不等于有权访问任意目的；禁止二层直通也不等于自动禁止网关转发。每项保护都需要与其实际生效位置对应。
