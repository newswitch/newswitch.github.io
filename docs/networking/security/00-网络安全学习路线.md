# 网络安全与 VPN 学习路线

网络安全不是一个“允许或拒绝”的开关。不同机制处理不同对象：身份是否可信、报文是否符合地址绑定、连接是否符合策略，以及数据经过不可信网络时是否受到保护。

| [AAA 与 802.1X](./aaa-8021x/00-AAA与8021X学习路线.md) | 谁在访问，允许什么，如何维护授权会话 |

| [IPsec VPN](./ipsec/00-IPsec学习路线.md) | 怎样在不可信路径上保护选定流量 |

## 2. 机制之间的关系

```text
身份认证 → 授权策略 → 设备执行访问约束
地址绑定 → 二层报文检查 → 限制不符合绑定的流量
业务选流 → IPsec 封装 → 远端解密后继续访问控制与路由
```

认证成功不会自动创建正确的 VLAN、DHCP 或路由；VPN 建立也不会自动批准远端访问全部内部系统。

建议先掌握地址、邻居、VLAN、DHCP 与路由，再分别学习本目录各机制。无线链路加密与漫游的关系见 [WLAN](../wireless/00-WLAN学习路线.md)。
