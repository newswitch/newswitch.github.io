# AAA 与 802.1X 学习路线

管理员登录交换机，与笔记本获得办公网访问权限，是两种不同的接入请求。它们都可能依赖 AAA，但入口、协议和需要执行的授权策略并不相同。

## 1. 阅读顺序

1. [AAA、RADIUS、TACACS+ 与设备管理](./01-AAA-RADIUS-TACACS与设备管理.md)：先分清认证、授权和审计，以及设备与认证服务器的交互。
2. [802.1X、EAP 与接入认证链路](./02-8021X-EAP与接入认证链路.md)：理解终端、接入设备和认证服务器之间怎样传递认证消息。
3. [EAP-TLS、证书授权与会话生命周期](./03-EAP-TLS证书授权与会话生命周期.md)：理解双向证书校验、策略执行、重认证和动态授权。

## 2. 需要持续区分的对象

| 对象 | 不能混淆为 |
| --- | --- |
| 用户或设备身份 | 当前 IP 或 MAC 的绝对可信声明 |
| 认证成功 | 自动获得所有网络权限 |
| Access-Accept | 所有授权属性都已成功落到数据面 |
| 会话审计记录 | 逐包抓取的完整流量内容 |
| 认证服务器可达性 | 终端到业务系统的端到端可达性 |

地址配置与接入授权的衔接可结合 [DHCP](../../services/dhcp/00-DHCP学习路线.md) 阅读。
