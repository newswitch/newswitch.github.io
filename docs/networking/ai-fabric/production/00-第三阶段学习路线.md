# 第三阶段：云原生与生产运维

设备和 Fabric 正常只是基础。生产平台还必须保证 Pod 拿到正确的 GPU、NIC、NUMA、
网络平面和权限，并能把一次训练变慢追溯到具体节点、端口、队列或通信 Rank。

## 阶段验收

- 能解释默认 CNI、辅助网络和 RDMA 资源的边界。
- 能按隔离与性能要求选择共享 RDMA 或 SR-IOV。
- 能证明 Pod 内 GPU、NIC 和 CPU 位于预期拓扑。
- 能把 Switch、NIC、RDMA、NCCL 和训练指标关联起来。
- 能在任务启动前阻止已知坏节点和坏 Rail。
- 能按故障域灰度修改 PFC、ECN、固件或驱动并自动停止。
- 能定义有测试口径的容量基线和训练网络 SLO。
