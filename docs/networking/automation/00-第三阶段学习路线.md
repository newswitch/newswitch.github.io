# 第三阶段：网络自动化与智能管控学习路线

## 阶段目标

自动化不是“把手工 CLI 放进循环”。生产级网络自动化应形成闭环：

```mermaid
flowchart LR
    A["Source of Truth"] --> B["生成候选配置"]
    B --> C["静态与拓扑验证"]
    C --> D["审批和分批发布"]
    D --> E["实时状态验证"]
    E --> F["Telemetry / SLO"]
    F --> G{"符合意图？"}
    G -- "是" --> H["记录证据并结束"]
    G -- "否" --> I["停止、回滚、复盘"]
```

## 阶段验收

- 自动化任务具有超时、重试边界、并发限制、审计和凭据隔离。
- 能区分意图状态、候选状态、运行配置和实时运行状态。
- 能在变更前验证语法、策略、邻居、可达性和故障域。
- 能分批发布，并用停止条件而不是“全部执行完成”判断成功。
- 失败时能根据快照和变更记录完成自动或人工回滚。
