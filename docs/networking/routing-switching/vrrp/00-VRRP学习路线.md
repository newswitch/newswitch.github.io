# VRRP 与网关冗余学习路线

终端通常只配置一个默认网关。VRRP 让多台设备共同维护一个虚拟路由器，使终端不必随着物理网关切换而重新配置地址。

## 1. 阅读顺序

1. [虚拟网关、通告与选举机制](./01-VRRP虚拟网关通告与选举机制.md)：理解虚拟 IP、虚拟 MAC、VRID、优先级和主备状态。
2. [收敛、双主与会话连续性](./02-VRRP收敛双主与会话连续性.md)：把协议切换、二层学习、上游可达和连接状态放在一起理解。

## 2. 先区分三类高可用

| 对象 | 需要连续的状态 |
| --- | --- |
| 网关入口 | 终端仍能把帧交给提供转发的设备 |
| 网络路径 | 新设备具有可用的去程和回程路由 |
| 业务会话 | NAT、防火墙或代理等状态足以继续处理旧连接 |

VRRP 主要解决第一项，不能单独包办后两项。学习前可先阅读 [IPv4 与路由表](../../fundamentals/03-IPv4子网划分与路由表.md)；理解有状态切换还需要 [NAT 与连接跟踪](../../security/firewall-acl-nat/01-NAT-ACL与连接跟踪.md)。
