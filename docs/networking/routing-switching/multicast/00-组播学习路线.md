# IGMP、PIM 与组播学习路线

组播把“发送一份数据”和“网络在分支处复制数据”结合起来。要理解它，需要把接收意愿、跨网段分发和二层出口裁剪分开。

## 1. 阅读顺序

1. [组播地址、IGMP/MLD 与成员关系](./01-组播地址IGMP-MLD与成员关系.md)：理解组、源、接口和主机成员状态。
2. [PIM-SM、共享树、源树与 RPF](./02-PIM-SM共享树源树与RPF.md)：理解跨路由网络如何形成分发树，以及 SSM 为什么不需要 RP。
3. [Snooping、Querier 与二层组播转发](./03-Snooping-Querier与二层组播转发.md)：理解交换机怎样知道应该把流量送到哪些端口。

## 2. 各层维护什么

| 位置 | 主要状态 |
| --- | --- |
| 应用与主机 | 哪个接口订阅哪些组与源 |
| 末跳路由器 | 本链路有哪些接收需求 |
| 中间路由器 | 分发树的入接口与出接口集合 |
| 二层交换机 | VLAN 内的成员端口、路由器端口与计时 |

“主机加入组”不等于整条路径的其他三种状态已经形成。单播路由、二层链路与地址作用域仍是理解组播的基础。
