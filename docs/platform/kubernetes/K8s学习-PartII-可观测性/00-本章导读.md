# 可观测性 · 本章导读

可观测性是现代云原生应用的基础能力，它帮助我们：

- **快速诊断问题**：通过完整的观测数据快速定位故障
- **优化性能**：识别瓶颈并进行针对性优化
- **提升可靠性**：通过主动监控预防问题发生
- **改进用户体验**：确保应用稳定运行并及时响应

在 Kubernetes 环境中实施可观测性需要综合考虑多个层次，从基础设施到应用的全方位覆盖。选择合适的工具栈并遵循最佳实践，可以构建强大而可靠的可观测性系统。

## 建议学习顺序

```text
Metrics / Logs / Traces
  → OpenTelemetry
  → LLM 服务 SLI/SLO
  → Error Budget 与 Burn Rate 告警
  → 事件响应与 RCA
  → Toil 与安全自动修复
```

前八篇解决“如何看到系统内部状态”，后四篇进一步解决：

1. 怎样从用户视角定义服务质量。
2. 怎样只对真正威胁 SLO 的问题告警。
3. 怎样沿请求、Pod、Node、GPU、网络和存储保留证据。
4. 怎样把重复处置变成可验证、可回滚的自动化。
