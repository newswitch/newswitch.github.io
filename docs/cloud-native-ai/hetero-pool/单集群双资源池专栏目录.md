# 单集群 GPU+NPU 双资源池专栏目录

面向小白：从一个 Kubernetes 集群里同时管好 **GPU 池 + NPU 池**，覆盖部署、调度、存储、推理上线与运维排障。

**原则**：GPU 侧、通用 K8s、存储、Ceph、vLLM 已有正文只引用，不重复写；本专栏只补「双池混合」与「NPU / 异构差异」。过深硬件细节不做。

**图例**：`【引用】`已有文章 · `【待写】`本专栏后续正文

> 完整周次式「学习路线」暂不单独成文；先按本目录推进即可。
