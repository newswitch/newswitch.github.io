# NVIDIA＋昇腾双资源池 AI 推理集群

**副标题**：从 0 到部署、运维与故障排查

本页为专栏总目录。各篇目前为**骨架**，可按编号填充正文。

---

## 系列定位

面向没有 AI 算力集群经验的读者，从基础概念开始，最终完成一个生产级双资源池 AI **推理**集群：

- 资源池 A：**NVIDIA GPU**（原生 vLLM）
- 资源池 B：**华为昇腾 NPU**（vLLM-Ascend）
- 统一 Kubernetes 控制面
- 共享网络、存储、镜像仓库、网关和监控
- 对外提供统一 OpenAI 兼容接口
- 建立两套专项运维和故障排查体系

---

## 技术边界

- NVIDIA：CUDA、NCCL、vLLM
- 昇腾：CANN、HCCL、vLLM-Ascend
- 两个资源池使用**独立运行镜像**
- 原始模型权重通常可共用；转换、量化、编译产物分别管理
- **单个分布式模型实例不能混合使用 NVIDIA GPU 和昇腾 NPU**
- 双池统一发生在：Kubernetes 管理、模型服务路由、运维监控层
