# 可观测性命令参考库

AI运维的可观测性命令不只是“查一个指标”。完整闭环是：配置在上线前可校验、规则可单元测试、告警能验证路由、静默有审计与期限、日志能按统一时间窗和请求ID导出。

## 1. 学习顺序 {/* #学习顺序 */}

1. [promtool](./01-promtool命令详解.md)：配置、规则、PromQL、TSDB和调试包。
2. [amtool](./02-amtool命令详解.md)：告警、Silence、路由树和配置验证。
3. [logcli](./03-logcli命令详解.md)：LogQL、标签基数、时间窗日志和本地复现。

## 2. 事故时间线 {/* #事故时间线 */}

```text
告警触发时间
→ amtool确认labels、startsAt与receiver
→ PromQL确认指标趋势与缺失
→ logcli按cluster/ns/pod/request-id取日志
→ Kubernetes/GPU/训练/推理命令补现场
→ 统一UTC时间线和不可变证据包
```

## 3. 安全边界 {/* #安全边界 */}

查询也可能对Prometheus/Loki产生高负载；先缩小时间窗与label。Silence、删除日志、重载配置和TSDB操作会改变生产状态，必须审批、限时和可追踪。Token、告警注释和日志可能包含敏感信息，导出时脱敏。

## 4. 验收 {/* #验收 */}

能在CI阻止错误规则；能证明一组labels最终进入哪个receiver；能设计有owner和到期时间的Silence；能从Loki导出不丢顺序的时间窗日志并识别高基数标签。
