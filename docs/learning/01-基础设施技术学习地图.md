# 基础技术学习地图

基础技术模块回答一个核心问题：数据从介质进入服务器后，如何经过 CPU、
内存、总线、网卡与 GPU，最终参与计算。

## 三条学习主线

| 主线 | 先解决的问题 | 入口 |
| --- | --- | --- |
| 计算与加速器 | GPU 如何执行计算，显存如何使用，卡间如何通信 | [计算与加速器学习路线](../gpu/00-GPU与加速计算学习路线.md) |
| 网络 | TCP/IP、数据中心网络、RDMA 和 AI 集群组网如何分层 | [网络技术学习路线](../networking/00-网络学习路线.md) |
| 存储 | 本地 NVMe、NFS、Ceph、对象存储与 CSI 如何选型 | [存储技术学习路线](../storage/00-存储技术学习路线.md) |

建议先学习 GPU 与 PCIe，再学习传统网络和 RDMA，最后进入存储。完成后应能
画出“磁盘或对象存储 → 主机内存 → PCIe → GPU 显存”的数据路径，并指出
GPUDirect RDMA、GPUDirect Storage 分别绕过了哪些传统环节。
