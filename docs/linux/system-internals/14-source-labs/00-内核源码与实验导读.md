# 内核源码与实验导读

源码学习的目标不是从第一行读到最后一行，而是从一个可观察行为出发，定位入口、核心对象、状态变化和退出路径，再用实验验证理解。

## 1. 三条约束

1. **版本一致**：源码、配置、符号和运行内核必须能对应。
2. **环境隔离**：可能 panic、死锁或破坏数据的实验放在 QEMU/测试机并保留控制台。
3. **结果可复现**：记录提交、配置、命令、输入、预期、原始输出和回滚方式。

## 3. 推荐闭环

```text
一个现象或系统调用
→ 找稳定接口/tracepoint
→ 定位入口函数和核心对象
→ 画出状态转换
→ 在隔离环境构造单变量实验
→ 对比 trace、计数器、返回值和源码
→ 写明版本差异与结论边界
```
