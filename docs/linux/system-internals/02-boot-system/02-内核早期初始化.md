# 内核早期初始化：从解压入口到第一个用户态进程

Bootloader 把内核映像、initramfs 和参数放到约定位置并移交控制权后，内核必须在几乎没有通用服务可用的环境中建立页表、内存管理、调度、中断和设备框架，最后执行第一个用户态程序。

## 1. 启动早期不能假设什么

刚进入内核时，不能假设以下能力已完整可用：

- 通用内存分配器。
- 完整页表和虚拟地址布局。
- 调度器和普通进程。
- 中断、定时器和设备驱动。
- 已挂载的真实根文件系统。
- 用户空间日志服务。

因此启动代码高度依赖 CPU 架构，必须按严格顺序逐层建立能力。

## 2. 概念执行路径

```text
架构启动入口
→ 解压并重定位内核
→ 建立初始页表和栈
→ 解析固件/Bootloader 信息
→ start_kernel()
→ 内存、调度、中断、时间等核心子系统
→ 各级 initcall 初始化内置组件和驱动
→ rest_init()
→ 创建 kernel_init 与 kthreadd
→ kernel_init 执行 /init 或真实根中的 init
```

`start_kernel()` 位于 `init/main.c`，是理解通用初始化顺序的重要入口，但之前已经执行了大量架构专用工作。

## 3. PID 0、PID 1 和 PID 2

- 早期启动任务最终成为每 CPU idle 调度实体的一部分，常被概念化为 PID 0/idle。
- `kernel_init` 最终进入用户空间，成为 PID 1。
- `kthreadd` 通常是 PID 2，负责派生其他内核线程。

PID 号是常见结果，不应把所有实现细节简化成“三个普通进程”。idle 任务、内核线程和用户进程的地址空间及职责不同。

## 4. initcall 是什么

编译进内核的组件通过不同级别 initcall 注册初始化函数，链接过程把它们组织起来，内核按级别调用。驱动初始化过慢或卡住会拖慢启动。

可在测试或恢复场景使用启动参数观察：

```text
initcall_debug
```

它会增加日志量，不应在没有容量评估时长期用于生产。官方还提供 `initcall_blacklist=` 辅助隔离有问题的内置初始化函数，但错误使用可能使必要设备消失。

## 5. 内核命令行如何影响启动

```bash
cat /proc/cmdline
```

常见参数包括：

| 参数 | 作用 |
|---|---|
| `root=` | 指定真实根设备 |
| `ro` / `rw` | 初次挂载根文件系统的模式 |
| `console=` | 指定控制台，可配置多个 |
| `init=` | 指定替代 init 程序 |
| `rd.*` | 常由 initramfs 工具解释的早期用户空间参数 |
| `panic=` | Panic 后等待或重启策略 |
| `quiet` | 减少控制台日志，不代表没有日志 |

内核无法识别且符合规则的部分参数可能传给 init；initramfs 工具也会读取 `/proc/cmdline`。所以命令行同时影响内核和早期用户空间。

## 6. 为什么早期日志特别重要

用户空间 journal 尚未运行时，错误只能进入内核 ring buffer、固件持久日志、串口、pstore/ramoops 等路径。系统成功启动后可使用：

```bash
journalctl -k -b
dmesg -T
journalctl --list-boots
```

`dmesg -T` 的人类时间转换可能受系统时钟校准影响，精确关联事件时优先保存原始 monotonic 时间和 journal 字段。

## 7. 常见停止位置

- `Unable to mount root fs`：根设备、驱动、文件系统或参数问题。
- `No working init found`：根中找不到可执行 init、解释器/库缺失、架构不匹配或权限错误。
- 某驱动 initcall 后无后续日志：驱动、固件或硬件初始化可能卡住。
- 日志突然消失但机器未重启：console 切换、输出目标改变或内核卡死都需要区分。

## 8. 练习与答案

**问题：为什么访问根磁盘所需的驱动不能都等 systemd 启动后再加载？**

答案：systemd 位于真实根文件系统中。若内核尚不能访问根磁盘，就无法执行 systemd，也无法从真实根读取驱动模块，因此关键模块必须内置或放在 initramfs。

**问题：`quiet` 是否会禁止内核记录错误？**

答案：通常主要降低控制台打印级别，不代表所有日志都不进入 ring buffer；具体还受 `loglevel`、驱动和持久日志配置影响。
