# pr 命令详解：分页、多栏、并排合并与打印格式

`pr` 把文本分页，并可排成多栏或把多个文件并排合并。默认每页 66 行、页眉 5 行、正文 56 行、页脚 5 行；它面向打印/人类显示，而不是结构化数据连接。

## 1. 命令档案

| 项目 | 内容 |
|---|---|
| 实现 | GNU coreutils |
| 文档基线 | GNU coreutils 9.11 |
| 安全级别 | `[R]`；会增加页眉/页脚、Form Feed、TAB 或截断文本 |
| 主要对象 | 页面、栏、显示字符、行号、页眉时间 |

```bash
type -a pr
env pr --version
env pr --help
```

## 2. 完整语法

```text
pr [OPTION]... [FILE]...
```

无文件时读取标准输入，`FILE=-` 也表示标准输入。默认按文件分别分页；`-m` 才把多个文件并排合并。

## 3. 全部参数：页面与页眉

| 短/旧式参数 | 长参数 | 作用 |
|---|---|---|
| `+FIRST[:LAST]` | `--pages=FIRST[:LAST]` | 只输出指定页面范围 |
| `-l N` | `--length=N` | 每页总行数，默认 66；N≤10 时省略页眉页脚 |
| `-h TEXT` | `--header=TEXT` | 用 TEXT 替换页眉中的文件名 |
| `-D FORMAT` | `--date-format=FORMAT` | 按 `date` 风格设置页眉时间格式/文字 |
| `-f`、`-F` | `--form-feed` | 用 Form Feed 而不是换行填充分页 |
| `-t` | `--omit-header` | 去掉页眉页脚和页面底部填充，保留输入 Form Feed |
| `-T` | `--omit-pagination` | 去掉页眉页脚，并消除输入 Form Feed |

页眉日期受 `TZ` 与 `LC_TIME` 影响，Page 文案受 `LC_MESSAGES` 影响。可重复构建应固定 Locale/TZ 或显式 `-D`。

## 4. 全部参数：栏与合并

| 参数 | 长参数 | 作用 |
|---|---|---|
| `-COLUMNS` | `--columns=COLUMNS` | 单文件输出 N 栏，默认按栏向下填充 |
| `-a` | `--across` | 多栏改为按行横向填充，须配合 N>1 |
| `-m` | `--merge` | 多文件并排，每个文件一栏；不能与 `-COLUMNS` 合用 |
| `-J` | `--join-lines` | 自由字段连接长行，关闭栏对齐和截断 |
| `-s[CHAR]` | `--separator[=CHAR]` | 用单字符分栏；与 `-w` 的截断行为存在 POSIX 兼容语义 |
| `-S[STRING]` | `--sep-string[=STRING]` | 用任意字符串分栏，不改变宽度/截断规则 |

多栏默认会为适应页面宽度而截断长行。`-J` 防止这种栏对齐截断，但输出可能非常宽。`-m` 类似显示层的并排，不按 Key 对齐，也不是 `join`。

## 5. 全部参数：宽度、缩进和间距

| 参数 | 长参数 | 作用 |
|---|---|---|
| `-w N` | `--width=N` | 仅多栏页面宽度，默认 72；与 `-s` 有历史交互 |
| `-W N` | `--page-width=N` | 单栏/多栏都使用的页面宽度；长行截断，除非 `-J` |
| `-o N` | `--indent=N` | 每行左侧缩进 N 个空格 |
| `-d` | `--double-space` | 输出双倍行距 |

页宽是字符/栏布局模型，不是可靠的 Unicode 终端显示宽度。页眉本身不会因宽度设置被截断。

## 6. 全部参数：行号、TAB 与不可见字符

| 参数 | 长参数 | 作用 |
|---|---|---|
| `-n[SEP[DIGITS]]` | `--number-lines[=SEP[DIGITS]]` | 行号，默认 5 位并用 TAB 分隔 |
| `-N N` | `--first-line-number=N` | 第一张实际输出页的起始行号 |
| `-e[CHAR[WIDTH]]` | `--expand-tabs[=CHAR[WIDTH]]` | 输入 TAB/指定字符按制表宽度展开 |
| `-i[CHAR[WIDTH]]` | `--output-tabs[=CHAR[WIDTH]]` | 输出空格重新压缩为 TAB/指定字符 |
| `-c` | `--show-control-chars` | 控制字符用 `^X`，其他不可打印字符用八进制转义 |
| `-v` | `--show-nonprinting` | 不可打印字符用八进制转义 |
| `-r` | `--no-file-warnings` | 不打印文件打不开警告，但退出仍为非 0 |
| 无 | `--help`、`--version` | 帮助与版本 |

`-e/-i/-n/-s/-S` 带可选参数时，短参数的黏连语法容易误读；自动化优先长参数和显式等号。

## 7. 页面示例

```bash
pr --length=50 --header='SRE Daily Report' --date-format='%F %T %Z' report.txt
pr --pages=2:4 -- report.txt
pr --omit-header --double-space -- report.txt
```

输入 Form Feed 会主动换页；未知文本先用 `od -An -tx1 -c` 检查 `\f`，否则页面计数可能意外变化。

## 8. 多栏与并排示例

```bash
# 单文件三栏，按栏向下
pr --columns=3 --page-width=120 -- names.txt

# 三栏，按行横向
pr --columns=3 --across --page-width=120 -- names.txt

# 两文件并排，用显式字符串分隔且不截断
pr --merge --join-lines --sep-string=' | ' before.txt after.txt
```

若需要可靠比较用 `diff`；按 Key 合并用 `join`；字段拼接用 `paste`。`pr -m` 只按相同行号展示。

## 9. 截断与数据安全

多栏或显式 `-W` 会截断超宽行，可能悄悄丢失：日志尾字段、哈希、路径、错误原因、JSON 后半部分。人类报告允许截断时，应给出原始证据链接并显示“已截断”规则；机器数据不能用 `pr` 转换后继续解析。

控制字符直接输出可能影响终端/打印机；用 `-c/-v` 也只是显示转义，不是安全清洗。输出到终端前仍需考虑 ANSI Escape 与双向 Unicode。

## 10. Locale、时间和可重复性

```bash
LC_ALL=C TZ=UTC0 pr \
  --date-format='%Y-%m-%dT%H:%M:%SZ' \
  --header='Inventory' inventory.txt
```

默认页眉可能使用文件 mtime 或当前/输入相关时间规则（视输入类型），不同版本和环境会让输出变化。将分页输出用于测试 Golden File 时，固定所有相关条件。

## 11. 退出状态与排查

成功为 0，任一输入打不开、参数或读写失败为非 0；`-r` 只隐藏警告，不改变失败状态。

| 现象 | 检查方向 |
|---|---|
| 每页正文不是 66 行 | 66 含页眉页脚，默认正文 56 行 |
| 页眉突然消失 | `-t/-T` 或 `--length<=10` |
| 长行内容丢失 | 多栏或 `-W` 截断；考虑 `-J` 或不用 pr |
| 栏顺序不符 | 默认向下填栏，横向需 `-a` |
| TAB/对齐异常 | `-e/-i`、终端 Tab Stop、宽字符 |
| 文件错误没提示但失败 | 使用了 `-r`，检查退出码/标准错误策略 |

## 12. 动手实验

1. 用 100 行输入验证默认页面的 5+56+5 结构。
2. 比较 `-3` 与 `-a -3` 的填充顺序。
3. 用两个长行文件比较 `-m`、`-m -J` 和 `paste`。
4. 比较 `-w`、`-W`、`-s`、`-S` 的截断与分隔。
5. 输入 TAB、BEL、Form Feed，用 `-c/-v/-e/-i` 观察。
6. 固定 `LC_ALL/TZ/-D` 生成可重复报告。

## 13. 掌握标准

- 能列出 `pr` 的全部专用参数族。
- 能计算页长、页眉、正文和页脚关系。
- 能区分按栏向下、Across 和 Merge。
