# nl 命令详解：逻辑页面、选择性行号与编号格式

`nl` 不只是“给每行加数字”。它把输入看作一个由逻辑页面组成的文档，每页又有 header、body、footer 三个区段，可以分别决定哪些行编号、编号何时重置以及如何格式化。

## 1. 命令档案

| 项目 | 内容 |
|---|---|
| 实现 | GNU coreutils |
| 文档基线 | GNU coreutils 9.11 |
| 安全级别 | `[R]`，转换后写标准输出 |
| 主要对象 | 逻辑页面、区段、行和编号状态 |

```bash
type -a nl
env nl --version
env nl --help
```

## 2. 完整语法

```text
nl [OPTION]... [FILE]...
```

无文件或 `FILE=-` 时读取标准输入。所有输入文件被视为同一份文档：文件边界不会自动重置行号或逻辑页面。

## 3. GNU coreutils 9.11 全部参数

| 短参数 | 长参数 | 作用 |
|---|---|---|
| `-b STYLE` | `--body-numbering=STYLE` | 正文区编号样式，默认 `t` |
| `-d CD` | `--section-delimiter=CD` | 设置组成区段标记的字符，默认 `\:` |
| `-f STYLE` | `--footer-numbering=STYLE` | 页脚区编号样式，默认 `n` |
| `-h STYLE` | `--header-numbering=STYLE` | 页眉区编号样式，默认 `n` |
| `-i N` | `--line-increment=N` | 每次编号增加 N，默认 1，可为负 |
| `-l N` | `--join-blank-lines=N` | 连续 N 个空行视为一条可编号逻辑行，只编号最后一个 |
| `-n FORMAT` | `--number-format=FORMAT` | 编号对齐和补零，默认 `rn` |
| `-p` | `--no-renumber` | 新逻辑页面开始时不重置编号 |
| `-s STRING` | `--number-separator=STRING` | 编号与正文间字符串，默认 TAB |
| `-v N` | `--starting-line-number=N` | 每个逻辑页面起始编号，默认 1，可为负 |
| `-w N` | `--number-width=N` | 编号字段宽度，默认 6 |
| 无 | `--help` | 显示帮助并退出 |
| 无 | `--version` | 显示版本并退出 |

## 4. STYLE 全集

`-b/-h/-f` 共用：

| STYLE | 含义 |
|---|---|
| `a` | 所有行都编号，包括空行 |
| `t` | 只编号非空行；body 默认 |
| `n` | 不编号；header/footer 默认 |
| `pBRE` | 只给匹配 GNU basic regular expression `BRE` 的行编号 |

```bash
nl -ba -- file
nl -bp'^ERROR' -- app.log
```

Shell 必须引用带元字符的样式。`pBRE` 的 `p` 与正则之间没有额外分隔符。

## 5. 逻辑页面和区段标记

默认用反斜杠 `\` 与冒号 `:` 组成精确标记行：

| 输入行 | 开始区段 |
|---|---|
| `\:\:\:` | header |
| `\:\:` | body |
| `\:` | footer |

标记行在输出中被替换为空行。第一个标记前的内容按 body 处理；没有任何标记的普通文件就是一个 body。

```bash
printf '\\:\\:\\:\nHeader\n\\:\\:\nBody\n\\:\nFooter\n' |
nl -ha -ba -fa
```

`-d XY` 改变构造标记的两个字符。只给一个字符时第二个仍是 `:`；GNU 扩展允许更多字符，也允许 `-d ''` 完全禁用区段识别。

当业务内容可能恰好出现标记行时，应禁用或改成不会冲突的分隔字符，否则内容会被替换为空行。

## 6. 编号格式

`-n FORMAT`：

| FORMAT | 含义 |
|---|---|
| `ln` | 左对齐，不补零 |
| `rn` | 右对齐，不补零，默认 |
| `rz` | 右对齐，前导零 |

```bash
nl -ba -n rz -w 4 -s ': ' -- file
```

输出类似：

```text
0001: first
0002: second
```

当数字超出 `-w` 宽度时不会截断，而会扩展输出。负数还需要符号位置。

## 7. 起始值、步长与页面重置

```bash
nl -ba -v 100 -i 10 -- file
nl -ba -v 10 -i -1 -- file
```

默认遇到新的逻辑页面会重新从 `-v` 开始。`-p` 让编号跨逻辑页面连续：

```bash
nl -p -ba -- document
```

多文件默认也当成同一文档；如果每个文件必须重新编号，应分别调用 `nl`，而不是一次传多个文件。

## 8. 连续空行 `-l`

```bash
nl -ba -l 3 -- file
```

连续三个真正空行被当作一条逻辑行，只给第三个编号；不足三个不编号。只含空格/TAB 的行不算空行。该状态可跨文件边界延续，因为输入是同一文档。

`-l` 只有在相应区段 STYLE 会编号空行时才容易观察，例如 `-ba`；默认 body `t` 本就不编号空行。

## 9. 与 `cat -n`、编辑器行号区别

| 方法 | 适合 |
|---|---|
| `cat -n` | 快速给所有行连续编号 |
| `cat -b` | 快速只编号非空行 |
| `nl` | 区段、正则、起始值、步长、对齐、空行组 |
| 编辑器行号 | 交互定位，不改输出内容 |

`nl` 输出中的编号属于新文本，不再是原文件字节偏移；把它作为后续解析输入前，应明确新分隔符不会与正文冲突。

## 10. 生产场景

### 10.1 生成审阅用配置快照

```bash
nl -ba -n rz -w 6 -s $'\t' -- app.conf > app.conf.numbered
```

保留原始文件用于机器加载，编号版仅供审阅。

### 10.2 只编号错误行

```bash
LC_ALL=C nl -bp'^ERROR[[:space:]]' -s ': ' -- app.log
```

这不是统计原始文件行号：未匹配行不递增，因此数字是“第几个错误”，不是错误所在物理行。要输出物理行号用 `grep -n` 或先 `nl -ba` 再过滤。

### 10.3 生成固定步长标签

```bash
nl -ba -v 0 -i 100 -n rz -w 8 -- records
```

编号可能溢出预设宽度，消费者不应依赖固定列截取。

## 11. 退出状态与排查

`0` 成功，非 `0` 表示参数、读取、正则或写入失败。

| 现象 | 检查方向 |
|---|---|
| 行突然不见只剩空行 | 内容误命中区段标记 |
| 页眉页脚不编号 | 默认 STYLE 是 `n` |
| 正则样式无效 | `pBRE` 拼接、BRE 语法、Shell 引用、locale |
| 第二个文件没有从 1 开始 | 多文件视为同一文档 |
| 空格行被编号 | 它不是空行 |
| 列对齐破坏 | 数字超过宽度、正文含 TAB、Unicode 显示宽度 |

## 12. 动手实验

1. 比较默认、`-ba`、`-bn`、`-bpBRE`。
2. 构造 header/body/footer，分别设置三种 STYLE。
3. 比较默认页面重置与 `-p`。
4. 使用负起始值和负步长。
5. 测试 `ln/rn/rz` 与小于数字长度的宽度。
6. 构造真正空行和只含空格的行，验证 `-l`。
7. 一次输入两个文件，再分别调用，比较编号状态。

## 13. 掌握标准

- 能列出 `nl` 全部参数及 STYLE/FORMAT 全部取值。
- 能解释逻辑页面、三个区段及默认标记。
- 能控制编号重置、起始值、步长、宽度和分隔符。
- 能说明正则选择编号不是原始物理行号。
- 能识别区段标记与业务内容冲突风险。
