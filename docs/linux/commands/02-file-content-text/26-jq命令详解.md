# jq 命令详解：JSON 流、Filter、变量、模块、退出状态与流式处理

`jq` 读取 JSON value 流，对每个输入执行 filter。`.` 是 identity，pipe 把前一 filter 的每个输出送给下一 filter；这与文本 pipeline 类似但保留 JSON 类型和结构。

## 1. 输入输出参数

```text
jq [OPTIONS] FILTER [FILES...]
```

| 参数 | 含义 |
|---|---|
| `-c, --compact-output` | 每个 JSON 紧凑单行 |
| `-r, --raw-output` | string 不带 JSON 引号 |
| `-j, --join-output` | raw 且不加换行 |
| `-0, --raw-output0` | string 后 NUL；含 NUL 时失败（新版本） |
| `-a, --ascii-output` | 非 ASCII 用转义 |
| `-S, --sort-keys` | 对象 key 排序 |
| `-C/--color-output`、`-M/--monochrome-output` | 强制颜色/禁颜色 |
| `--tab`、`--indent N` | pretty 缩进 |
| `-s, --slurp` | 全部输入 value 组成数组后只运行一次 |
| `-R, --raw-input` | 每行文本 string，而非解析 JSON |
| `-n, --null-input` | 不读输入，以 null 执行一次 |
| `--stream` | SAX-like `[path,value]` 流，适合大 JSON |
| `--stream-errors` | stream 中把解析错误也变 value |
| `--seq` | RFC 7464 JSON Text Sequence |
| `--unbuffered` | 每个输出后 flush |

## 2. 变量与模块

| 参数 | 含义 |
|---|---|
| `--arg name value` | 以 string 绑定 `$name` |
| `--argjson name JSON` | 解析 JSON value 后绑定 |
| `--slurpfile name file` | 文件所有 JSON values 成数组 |
| `--rawfile name file` | 整个文件成 string |
| `--args`、`--jsonargs` | 剩余参数进入 `$ARGS.positional/named` |
| `-L DIR` | module 搜索目录；给出后不再使用 builtin search list |
| `-f FILE, --from-file=FILE` | filter 从文件加载 |

```bash
jq --arg ns "$namespace" '
  [.items[] | select(.metadata.namespace == $ns) |
   {name: .metadata.name, phase: .status.phase}]
' pods.json
```

不要把用户值拼进 filter；用 `--arg/--argjson` 保留类型并防 filter 注入。

## 3. 核心语言

- 取值：`.a`、`.a?`、`.[0]`、`.[]`；
- 构造：`{name: .metadata.name}`、`[.items[] | ...]`；
- 选择：`select(expr)`、`map(f)`、`has(key)`；
- 转换：`to_entries/from_entries`、`group_by/sort_by/unique_by`；
- 更新：`.a = x`、`.a |= f`、`del(path)`；
- 错误：`try/catch`、`error`、`halt_error(code)`；
- reduce/foreach 用于显式流聚合。

## 4. 退出状态

默认 filter 输出 `false/null` 仍可能退出 0。`-e, --exit-status`：最后输出既非 false 也非 null 为 0；false/null 为 1；无有效输出为 4；编译/系统错误用其他状态。自动化判断条件要用 `-e` 并区分状态。

```bash
if jq -e '.ready == true' status.json >/dev/null; then ...; fi
```

## 5. 大文件与安全

`--slurp` 把全部内容进内存；大 JSON 使用普通 value stream 或 `--stream` 并限制聚合。JSON string 可能含换行，`-r` 行输出不适合任意值边界；新版本用 `--raw-output0`，旧版本编码为 JSON/TSV/Base64 或明确协议。
