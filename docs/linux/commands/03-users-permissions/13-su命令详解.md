# su 命令详解：登录式身份切换、PAM 与环境边界

`su` 通过 PAM 认证后，以替代用户和组身份运行 shell 或命令。它主要面向交互用户；root 脚本应优先考虑 `runuser`，不需要 PAM session 时可考虑 `setpriv`，需要按策略授权和审计时使用 `sudo`。

## 1. 语法与完整参数

本文以 util-linux 实现为基线；某些系统使用 shadow-utils 或 sudo-rs 的 `su`，参数会不同。

```text
su [options] [-] [user|UID [argument...]]
```

| 短参数 | 长参数 | 作用 |
|---|---|---|
| `-c CMD` | `--command CMD` | 将字符串作为 shell `-c` 命令；创建新 session |
| `-f` | `--fast` | 把 `-f` 传给 shell，语义由 shell 决定 |
| `-g GROUP` | `--group GROUP` | 指定主组；仅 root |
| `-G GROUP` | `--supp-group GROUP` | 指定补充组；可重复，仅 root；无 `-g` 时首个也作主组 |
| `-` / `-l` | `--login` | 登录式 shell：清理环境、设置身份变量、切 home |
| `-m` / `-p` | `--preserve-environment` | 保留环境；与 `--login` 同用时被忽略 |
| `-P` | `--pty` | 为会话创建独立伪终端，隔离终端注入 |
| `-s SHELL` | `--shell SHELL` | 指定 shell；受 `/etc/shells` 和调用者权限限制 |
| 无 | `--session-command CMD` | 类似 `-c` 但不创建新 session；不推荐 |
| `-T` | `--no-pty` | 明确不创建伪终端 |
| `-w LIST` | `--whitelist-environment LIST` | 登录式清理时保留逗号分隔变量；不能保留核心身份变量 |
| `-h` | `--help` | 显示帮助 |
| `-V` | `--version` | 显示版本 |

## 2. 默认 `su` 与 `su -`

```bash
su alice
su --login alice
# 传统等价简写
su - alice
```

默认形式为兼容性通常保留当前目录和较多环境，容易混入原用户的 PATH、代理、语言、工具配置和不可访问目录。`--login` 更接近一次干净登录：清理大部分环境，设置 HOME/SHELL/USER/LOGNAME/PATH，进入目标 home，并启动 login shell。

`su --login` 仍不等于 systemd-logind 意义上的完整新会话；需要用户 runtime dir、cgroup/session 语义时使用 `systemd-run`、`machinectl` 或真实登录流程。

## 3. 认证、PAM 与“谁的密码”

普通用户切换时通常输入目标用户密码；root 常由 `pam_rootok` 放行。wheel 组限制、account/session 模块、limits 和环境最终由 `/etc/pam.d/su`、`su-l` 及 PAM 配置决定。

```bash
grep -Ev '^(#|$)' /etc/pam.d/su /etc/pam.d/su-l 2>/dev/null
getent passwd alice
grep -Fx "$(getent passwd alice | cut -d: -f7)" /etc/shells
```

不要把 `su` 失败简单归因于密码：账户过期、shell 限制、PAM access、SSSD、资源限制和审计策略都可能拒绝。

## 4. 运行命令和引用边界

```bash
su --login alice --command 'id && umask && pwd'
```

`-c` 接受一整段 shell 字符串。把未可信输入拼进去会产生 shell 注入；自动化若已有 root，优先使用可保持 argv 边界的：

```bash
runuser --user alice -- /usr/bin/id -a
```

如需交互终端，`--pty` 可隔离共享 TTY 的 `TIOCSTI/TIOCLINUX` 风险；是否启用仍需结合输入是否为管道、job control 和版本。

## 5. 环境、资源限制与退出码

即使指定 `--login/--preserve-environment`，PAM 仍可最终修改环境。util-linux 2.38 起还重置若干资源限制；不要假设从 root shell 继承的 ulimit 会保持不变。

`su` 正常返回子命令退出码；被信号终止时通常为 `128+signal`；自身在执行前失败返回 `1`，命令不可执行为 `126`，未找到为 `127`。

```bash
su --login alice --command 'exit 42'
printf 'rc=%d\n' "$?"
```

## 6. 实验与掌握标准

比较 `su alice` 与 `su - alice` 的 cwd/env/umask/id/ulimit；测试目标 shell 不在 `/etc/shells`、账户过期和 PAM 拒绝；比较 `-c` 与 `--pty` 的会话和信号行为。

掌握标准：能列出全部参数；能解释认证、PAM account/session 和环境的执行顺序；能在交互 `su`、root 自动化 `runuser`、细粒度授权 `sudo` 之间做出选择。
