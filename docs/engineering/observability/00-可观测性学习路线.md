# 可观测性学习路线

AI Infra 的可观测性需要跨越多层信号：

```text
业务请求与 SLO
→ 网关排队和模型服务批处理
→ Pod、节点与调度事件
→ GPU 利用率、显存、功耗、Xid
→ 网络吞吐、丢包、RDMA 计数器
→ 存储延迟、吞吐与队列深度
```

先学习 `gpu/` 中的 DCGM Exporter、Prometheus 告警和 Grafana 总览，再把
GPU 指标与 TTFT、TPOT、吞吐、请求失败率关联。最终目标是从一条 SLO 告警
快速缩小到具体层级，而不是仅仅收集更多指标。
