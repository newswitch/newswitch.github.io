# 第二阶段：AI Fabric 与无损网络

这一阶段不追求“所有包永远不丢”，而是设计一个低丢包、低抖动、拥塞可反馈、
故障可隔离的 Fabric。PFC 是最后一道保护，不是容量规划和拥塞控制的替代品。

## 阶段验收

- 从 GPU 数、NIC 数和端口速率计算无收敛与收敛设计。
- 解释每个 Rail 的故障域和 NCCL 使用方式。
- 追踪 DSCP→PCP→Priority→Traffic Class→Queue。
- 用 Pause、ECN Mark、CNP、队列水位和丢弃计数判断拥塞机制。
- 区分热点、微突发、PFC 扩散、死锁与链路错误。
- 对单链路、单 Rail、错误阈值和错误映射进行故障演练。
