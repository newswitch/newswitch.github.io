# 网络技术学习路线

网络模块不是只学习“网卡”。它需要同时理解协议栈、交换网络、主机数据路径、
无损网络以及分布式训练的集合通信。

## 推荐顺序

1. **传统组网**：从二三层、路由、负载均衡进入数据中心网络。
2. **Linux 高性能网络**：理解内核收包、软中断、队列、DPDK 与零拷贝。
3. **RDMA**：掌握 Queue Pair、Memory Region、Send/Receive、RDMA Read/Write。
4. **AI 集群网络**：比较 InfiniBand 与 RoCE，学习 GPUDirect RDMA 和多机 GPU 通信。
5. **Nginx 与网关**：补齐推理服务入口、TLS、日志和流量治理。

完成后继续阅读[GPU 网卡存储联合拓扑调度](../../projects/end-to-end/05-GPU网卡存储联合拓扑调度.md)，
将网络拓扑与 Kubernetes 调度联系起来。
