# 传统组网第三阶段：自动化与智能管控

**核心目标**：解放双手，从「配置工」进阶为「架构师」。  

---

## 1. 网络自动化开发与落地

### 核心学习内容

1. Python 基础语法、网络编程相关模块（re、logging、os）
2. Netmiko/Napalm 库实现多厂商网络设备 SSH 交互、配置管理
3. Ansible 核心原理（Inventory、Playbook、网络专用 Module）
4. Jinja2 模板实现网络设备标准化配置批量生成
5. 网络配置自动备份、批量下发、合规校验、状态巡检自动化实现
6. VS Code 开发环境搭建、代码调试、异常处理机制

### 必做实操项目

1. 基于 Python+Netmiko 编写脚本，实现 100 台交换机配置批量备份、版本批量核查、端口状态批量巡检
2. 基于 Ansible+Jinja2 模板，实现交换机标准化开局配置批量生成与下发，适配不同设备型号
3. 搭建网络设备自动巡检平台，实现 CPU / 内存、路由条目、邻居关系、告警信息的自动采集与报表输出

### 验收标准

- 能独立编写网络自动化脚本与 Ansible Playbook，实现「一杯咖啡时间搞定 100 台交换机」的批量管理需求
- 脚本可适配多厂商设备，具备完善的异常处理能力，能替代 80% 以上的重复手工配置工作
- 能基于业务需求，设计并落地标准化的网络自动化运维方案

### 配套学习资源 / 工具

- 工具：VS Code、Python 3.8+、Ansible、Git、EVE-NG 模拟器
- 书籍：《Python 网络编程权威指南》《Ansible for Networking》
- 课程：网络自动化 Python 实战专项、华为 HCIE-Datacom 自动化专项

## 2. SD-WAN 智能广域网

### 核心学习内容

1. SD-WAN 核心架构（控制 / 转发 / 管理平面分离）核心理念
2. SD-WAN Underlay 与 Overlay 网络设计、隧道技术
3. 应用感知路由（App-aware Routing）实现原理、多链路智能选路
4. 链路质量检测（丢包 / 时延 / 抖动）、故障秒级切换机制
5. 零配置部署（ZTP）、广域网优化、安全集成、多分支组网设计

### 必做实操项目

1. 搭建 4 分支 + 1 总部的 SD-WAN 拓扑，实现专线 + 互联网双链路的混合广域网组网
2. 配置应用感知智能选路，实现语音 / 视频业务优先走低时延专线，普通互联网业务走宽带链路
3. 验证链路故障时业务秒级切换，完成选路策略异常、隧道不通等故障排障

### 验收标准

- 彻底理解 SD-WAN 控制与转发分离的核心思想，能独立完成企业级多分支 SD-WAN 网络的规划与部署
- 能基于应用类型、链路质量实现智能选路，解决广域网链路利用率低、关键业务卡顿、分支部署复杂等行业痛点

### 配套学习资源 / 工具

- 工具：EVE-NG 模拟器（VMware SD-WAN / 华为 SD-WAN 镜像）
- 书籍：《SD-WAN 架构与技术》
- 文档：主流 SD-WAN 厂商官方技术白皮书

## 3. QoS 流量工程与服务质量保障

### 核心学习内容

1. QoS 服务模型（Best-Effort、IntServ、DiffServ）
2. 流量分类与标记（ACL、DSCP/802.1p）、端到端标记原则
3. 流量整形与监管（CAR、GTS）、带宽限速实现
4. 拥塞管理（FIFO、PQ、CQ、WFQ、CBWFQ、LLQ 低时延队列）
5. 拥塞避免（WRED 尾丢弃）、端到端 QoS 部署方案设计

### 必做实操项目

1. 在广域网链路上部署端到端 QoS 方案，对语音、视频、核心业务、普通流量进行分层分类标记
2. 通过 LLQ 队列保障语音业务低时延、低抖动，通过 CBWFQ 保障核心业务带宽，通过 WRED 避免全局同步
3. 在带宽拥塞场景下，验证关键业务的 SLA 达标情况，完成 QoS 策略异常、业务卡顿等问题排障

### 验收标准

- 能独立完成端到端 QoS 方案的设计与部署，在带宽有限的场景下，精准控制不同业务的带宽分配与转发优先级
- 能保障语音 / 视频等关键业务的 SLA（时延、抖动、丢包率）符合要求，彻底解决网络拥塞导致的业务卡顿问题

### 配套学习资源 / 工具

- 工具：EVE-NG/ENSP 模拟器、Wireshark、IxChariot 流量打流工具
- 书籍：《QoS 设计与实现》
- 课程：华为 HCIE-Datacom QoS 专项
