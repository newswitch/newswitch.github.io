# 分布式训练学习路线

## 1. 推荐顺序 {/* #推荐顺序 */}

1. [Kubernetes 分布式训练基础](./distributed/01-Kubernetes%20分布式训练基础.md)：理解 Worker、Rank、Rendezvous 与 Gang Scheduling。
2. [PyTorch DDP](./distributed/02-PyTorch%20DDP%20在%20Kubernetes%20中的部署.md)：建立数据并行和梯度同步的基本模型。
3. [NCCL](./distributed/05-NCCL%20通信原理与常见问题.md)：理解 Ring/Tree、通道、网卡选择与跨机集合通信。
4. [DeepSpeed ZeRO](./distributed/03-DeepSpeed%20ZeRO%20与%20GPU%20显存优化.md)：学习参数、梯度与优化器状态的分片。
5. [PyTorch FSDP2 学习路线](./fsdp2/00-PyTorch-FSDP2从零到生产学习路线.md)：掌握 DTensor、DeviceMesh、fully_shard、混合精度和分布式 Checkpoint。
6. [Megatron Core 学习路线](./megatron-core/00-Megatron-Core从零到生产学习路线.md)：掌握 TP、PP、CP、EP、Sequence Parallel、MoE 和通信重叠。
7. [大模型强化学习与 RL Infra 学习路线](./rl-infra/00-大模型强化学习与RL-Infra学习路线.md)：掌握PPO、GRPO、Rollout、Reward、Router Replay与权重同步闭环。
8. [Kubeflow Trainer 学习路线](./kubeflow-trainer/00-Kubeflow-Trainer从零到生产学习路线.md)：理解 TrainJob、Runtime、JobSet、Kueue/Volcano 和训练控制面。
9. [Slurm 与 HPC 训练集群学习路线](./slurm/00-Slurm与HPC训练集群从零到生产学习路线.md)：掌握 Partition、QOS、GRES/TRES、PMIx/MPI、NCCL/RDMA 与 HPC 容器。
10. [AI 训练数据面学习路线](../../storage/training-data-plane/00-AI训练数据面从零到生产学习路线.md)：追踪 Dataset Shard、DataLoader、并行文件系统、缓存、H2D 和 Checkpoint Storm。
11. [Checkpoint](./distributed/04-训练任务%20Checkpoint%20与断点恢复.md)：设计训练中断后的恢复与数据一致性。
12. [昇腾分布式训练与 HCCL](./distributed/07-昇腾PyTorch分布式训练与HCCL排障.md)：把 DDP、Rank、torch-npu、CANN 和 HCCL 落到 Ascend 集群。
13. [TorchTitan](./frontier/01-TorchTitan与PyTorch原生大模型训练架构.md)与[JAX、XLA、PJRT](./frontier/02-JAX-XLA-PJRT与分布式训练执行模型.md)：选修不同训练执行栈。
14. [分布式训练命令参考库](./commands/00-分布式训练命令参考库.md)：使用 torchrun、DeepSpeed、Accelerate、Ray 和 MPI 验证进程与作业对象。

学习时将每个 step 拆成计算、卡内通信、跨卡通信、跨机通信、数据读取和
Checkpoint 写入六段。这样才能判断瓶颈来自 GPU、NVLink、网卡还是存储。

命令学习不以背参数为目标。完成本模块后，应能从调度对象追到节点、进程、rank、GPU/NPU物理设备、NCCL/HCCL网络、数据Shard和checkpoint，并定位第一个失败rank。

## 2. 技术分层

```text
Kubeflow Trainer / Kueue / Volcano / Slurm：任务声明、配额准入与资源编排
→ torchrun / srun / mpirun：进程启动、Rank与Rendezvous
→ DDP / FSDP2 / Megatron Core / DeepSpeed：并行、状态分片与训练执行
→ NCCL / HCCL：集合通信
→ GPU / NPU / 网络 / 存储：物理数据路径
```

Kubeflow Trainer 不替代 FSDP2 或 Megatron Core；后两者也不负责 Kubernetes 配额与 Pod 放置。能准确判断故障位于哪一层，是完成本路线的重要标准。
