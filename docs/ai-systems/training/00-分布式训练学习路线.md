# 分布式训练学习路线

## 推荐顺序

1. [分布式训练命令参考库](./commands/00-分布式训练命令参考库.md)：先用 torchrun、DeepSpeed、Accelerate、Ray 和 MPI 建立进程与作业对象模型。
2. [Kubernetes 分布式训练基础](./distributed/01-Kubernetes%20分布式训练基础.md)：理解 Worker、Rank、Rendezvous 与 Gang Scheduling。
3. [PyTorch DDP](./distributed/02-PyTorch%20DDP%20在%20Kubernetes%20中的部署.md)：建立数据并行和梯度同步的基本模型。
4. [NCCL](./distributed/05-NCCL%20通信原理与常见问题.md)：理解 Ring/Tree、通道、网卡选择与跨机集合通信。
5. [DeepSpeed ZeRO](./distributed/03-DeepSpeed%20ZeRO%20与%20GPU%20显存优化.md)：学习参数、梯度与优化器状态的分片。
6. [Checkpoint](./distributed/04-训练任务%20Checkpoint%20与断点恢复.md)：设计训练中断后的恢复与数据一致性。

学习时将每个 step 拆成计算、卡内通信、跨卡通信、跨机通信、数据读取和
Checkpoint 写入六段。这样才能判断瓶颈来自 GPU、NVLink、网卡还是存储。

命令学习不以背参数为目标。完成本模块后，应能从调度对象追到节点、进程、rank、GPU UUID、NCCL网络和checkpoint，并定位第一个失败rank。
