# 分布式训练学习路线

## 推荐顺序

1. Kubernetes 分布式训练基础：理解 Worker、Rank、Rendezvous 与 Gang Scheduling。
2. PyTorch DDP：建立数据并行和梯度同步的基本模型。
3. NCCL：理解 Ring/Tree、通道、网卡选择与跨机集合通信。
4. DeepSpeed ZeRO：学习参数、梯度与优化器状态的分片。
5. Checkpoint：设计训练中断后的恢复与数据一致性。

学习时将每个 step 拆成计算、卡内通信、跨卡通信、跨机通信、数据读取和
Checkpoint 写入六段。这样才能判断瓶颈来自 GPU、NVLink、网卡还是存储。
