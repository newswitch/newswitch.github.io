# 大模型系统学习地图

这个模块从“GPU 能运行”继续走向“模型服务能稳定交付”。

## 1. 学习分支 {/* #学习分支 */}

- [AI 运行环境命令参考库](./runtime/commands/00-AI运行环境命令参考库.md)：Python、依赖锁定以及 CUDA/NCCL/cuDNN 动态库诊断。
- [模型制品命令参考库](./models/commands/00-模型制品命令参考库.md)：Hugging Face、Git LFS、不可变 revision 与缓存治理。
- [大模型推理学习路线](./inference/00-大模型推理学习路线.md)：请求生命周期、KV Cache、批处理、并行策略、启动与运行期故障排查、Kubernetes 部署与服务治理。
- [分布式训练学习路线](./training/00-分布式训练学习路线.md)：DDP、NCCL、ZeRO、Checkpoint 与多机训练。
- [MLOps 学习路线](./mlops/00-MLOps学习路线.md)：实验、模型、制品、评测门禁、发布与回滚。

## 2. AI 运维命令闭环 {/* #ai-运维命令闭环 */}

```text
Python / 动态库
→ hf / Git LFS 模型制品
→ torchrun / DeepSpeed / Accelerate / Ray / MPI
→ vLLM / Triton / HTTP / gRPC
→ vLLM bench / GenAI-Perf / Perf Analyzer
→ MLflow / DVC / Argo CD / Trivy / Cosign / ORAS
```

推理和训练共享 GPU、网络、存储与调度底座，但资源模型不同：推理关注 TTFT、
TPOT、吞吐、并发与 KV Cache；训练关注 step time、扩展效率、通信占比与
Checkpoint 恢复时间。
