## 3. 分类边界

- MySQL/PostgreSQL 保存事务事实，所以属于关系数据库，不属于大数据工程。
- Redis 的主问题是低延迟内存访问、缓存与临时状态，所以归入缓存。
- Kafka/RocketMQ 负责事件传输、缓冲与重放，所以归入消息与事件。
- Elasticsearch 面向倒排、全文与混合搜索；Milvus 面向大规模向量检索，两者分别归档。
- ClickHouse、Trino、Doris 面向列式聚合和交互式分析，统一归入 OLAP 与分析数据库。
- Hadoop、Spark、Flink、Iceberg、Airflow 与数据治理共同构成大数据工程主线。

一项技术只保留一个正文归属。例如 Kafka 位于“消息与事件”，大数据工程文章需要 Kafka 时通过链接引用，不复制另一套 Kafka 正文。
