# 机柜、U 位、滑轨、线缆、热通道与整机可维护性

服务器能在实验台上启动，不代表可以安全上架。机柜部署还受到高度、深度、重量、重心、供电、气流、线缆弯曲半径和维护空间约束。高密度 GPU 服务器的物理问题会直接变成温度、链路和可用性问题。

## 1. 机柜坐标

传统机柜以 Rack Unit 表示高度：

```text
1U = 1.75 英寸 = 44.45 mm
```

资产记录应至少包含：

```text
Data Center / Room
→ Row
→ Rack
→ U Position
→ Chassis
→ Node / Slot / FRU
```

只记录 IP 地址无法指导现场人员找到正确设备。

## 2. 高度、宽度和深度

- 19 英寸表示安装标准的一部分，不是机柜全部外形；
- 服务器前面板高度按 U 计算；
- 机箱深度必须给后部 Cable 和弯曲半径留空间；
- 机柜门、Rear-door Heat Exchanger 会继续占用深度；
- OCP Open Rack 可能使用不同宽度和 OU 体系。

长机箱即使能放入柜体，也可能与后门、PDU 或线缆冲突。

## 3. 承重和重心

GPU 服务器、UPS/BBU 和存储节点可能非常重。部署要核对：

- 机柜静态/动态承重；
- 地板载荷；
- 滑轨额定载荷；
- 设备重心；
- 机柜固定和防倾倒；
- 运输路径、电梯和升降工具。

重设备通常优先放在机柜下部，避免抬高重心；但仍要同时满足布线、散热和厂商要求。

## 4. 滑轨

常见滑轨：

- Fixed Rail：结构简单，拉出维护能力有限；
- Sliding Rail：可把服务器拉出机柜；
- Tool-less Rail：快速卡入兼容立柱；
- Cable Management Arm：在拉出时管理 Cable。

检查：

- 方孔、圆孔或螺纹孔；
- 机柜立柱间距；
- Rail 左右和前后方向；
- 拉出后是否需要支撑；
- CMA 是否压迫高速 Cable。

## 5. 前维护与后维护

| 部件 | 常见维护方向 |
| --- | --- |
| HDD/NVMe | 前部，也可能后部 |
| PSU | 后部 |
| OCP NIC/PCIe Card | 后部或开盖 |
| Fan | 前部、顶部或内部 |
| DIMM/CPU | 通常停机开盖 |
| Liquid Quick Disconnect | 前/后或 Blind-mate |

机柜相邻位置必须留出抽拉、拔插和人员操作空间。可热插拔不表示无需变更流程。

## 6. FRU 与 CRU

- FRU：Field Replaceable Unit，可由现场工程流程更换；
- CRU：Customer Replaceable Unit，设计为客户可更换；
- Non-FRU：通常需要返厂或更换更大组件。

FRU 边界可能是单盘、Riser、主板、GPU Baseboard 或整机节点。更细粒度维修不一定更好，还要看错误隔离、备件和修复风险。

## 7. Blind-mate

Blind-mate Connector 允许设备沿滑轨插入时自动连接：

- Power Busbar；
- 液冷 Manifold；
- Midplane 高速信号；
- 管理连接。

它提高维护效率，但对机械公差、插拔寿命、污染和对准要求很高。未完全就位可能造成接触电阻升高或链路不稳。

## 8. 冷通道与热通道

```text
冷通道
→ 服务器进风面
→ 服务器内部风道
→ 服务器排风面
→ 热通道
```

需避免：

- 空 U 位未装盲板，热风回流；
- 前后方向装反；
- 不同 Airflow 方向的交换机混装；
- Cable 堵住排风；
- 高功率设备排风直接加热上方设备进风。

Containment 只能管理机房气流，不能修复服务器内部 Heat Sink 接触或风扇故障。

## 9. 机柜功率密度

机柜不是把设备额定功率简单相加，还要计算：

- A/B Feed 容量；
- PDU Branch Circuit；
- 单 PSU 故障后的负载；
- 峰值和瞬态；
- 相位平衡；
- 插座、Cable 和 Connector 额定；
- 冷却能力。

高密度 GPU 服务器可能在电力还有余量时先受冷却或液冷接口数量限制。

## 10. 网络和光纤布线

### 10.1 铜缆/DAC

- 确认长度和支持速率；
- 避免过小弯曲半径；
- 防止重量拉扯 Port；
- 标记两端和中间路径。

### 10.2 光纤/AOC

- 区分单模/多模、Connector 和极性；
- 保持端面清洁；
- 使用合理弯曲半径；
- 光纤配线架记录端到端链路；
- 避免遮挡风道和维护部件。

### 10.3 管理线缆

业务、存储、训练和带外管理应有清晰颜色/标签和交换机 Port 映射，避免故障时拔错线。

## 11. Cable Management

良好布线需要：

- 明确 A/B 电源路径；
- 避免 Signal Cable 与高功率 Cable 不合理缠绕；
- 给滑轨运动留 Service Loop；
- 不阻挡 Fan/PSU/Drive 抽取；
- 高速 Cable 不被 CMA 急弯；
- 标签不遮挡光模块散热。

“线越短越好”不是唯一目标，还要能维护和满足信号规范。

## 12. 液冷机柜

液冷增加：

- Facility/Technology Water Pipe；
- CDU；
- Rack Manifold；
- Quick Disconnect；
- Drip Tray 和 Leak Sensor；
- 排气、Drain 和维护空间。

上架前必须完成压力、流量、清洁度、材料兼容和泄漏联锁验收。盲接液路也需要确认完全就位。

## 13. 设备编号和灯光定位

现场更换前应建立：

```text
CMDB Node ID
↔ Chassis Service Tag
↔ BMC MAC/IP
↔ Rack/U
↔ Slot/Port
↔ Device Serial
```

Locate/UID LED 只是辅助，仍应交叉核对序列号和业务摘除状态。不要把“灯亮的机器”作为唯一确认。

## 14. 上架验收

1. 核对机柜、U 位、Rail 和承重；
2. 核对 A/B 电源和输入规格；
3. 核对 Airflow 或液冷接口；
4. 核对业务、存储、训练和管理网络；
5. 检查 Cable 弯曲半径和维护空间；
6. 更新 CMDB、Port Map 和拓扑；
7. 上电检查 BMC、SEL、Sensor、PSU/Fan；
8. 执行 Burn-in 和满载温度/功率测试；
9. 演练 Locate、摘除和部件更换。

## 15. 常见现场故障

| 现象 | 可能原因 |
| --- | --- |
| 上架后 PCIe 降速 | Riser/Cable 受力、Connector 未就位 |
| 高负载过热 | 热回流、盲板缺失、Cable 堵风 |
| 拉出服务器后链路断 | Service Loop/CMA 长度不足 |
| 单路掉电 | A/B Cable 标签或 PDU Port 错误 |
| 光链路间歇错误 | 弯曲、污染、拉力、模块温度 |
| 液冷节点流量低 | QD 未就位、阀门、气堵、Manifold |

## 16. 练习与答案

**问题：服务器功率和 U 位都未超过机柜容量，是否就能继续上架？**

答案：不能。还需检查承重、重心、深度、PDU 支路、A/B 冗余、冷却、网络 Port、线缆空间和维护通道。

**问题：设备支持热插拔，是否可以不做业务摘除直接更换？**

答案：不能。热插拔只说明硬件支持带电操作，还需要上层副本/阵列允许、正确定位、停止 I/O、执行平台 Remove/Power-off 流程并验证重建。
