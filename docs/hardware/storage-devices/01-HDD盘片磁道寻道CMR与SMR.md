# HDD 盘片、磁道、寻道、CMR 与 SMR

HDD 的性能边界来自机械运动。它可以持续顺序传输大量数据，但面对跨磁道随机请求时，每次 I/O 都可能等待磁头移动和目标扇区旋转到位。

## 1. 物理结构

```text
Spindle Motor（主轴电机）
  └── 多张 Platter（盘片）
        ├── Surface（记录面）
        ├── Track（同心磁道）
        └── Sector（可寻址数据单元）

Actuator（执行器）
  └── Arm → Head（磁头）
```

同一半径上多个记录面的磁道可视为 Cylinder 的传统概念。现代硬盘由固件完成逻辑块地址到物理位置映射，主机通常只看到连续 LBA。

## 2. 一次读 I/O 的时间

```text
总延迟 ≈ 排队时间
       + 寻道时间
       + 旋转等待
       + 数据传输
       + 控制器/协议开销
```

- Seek：执行器把磁头移动到目标磁道；
- Rotational Latency：等待目标扇区转到磁头下；
- Transfer：连续经过磁头时读取数据；
- Queueing：前面请求的调度与等待。

顺序 I/O 减少寻道，随机 I/O 则受机械次数限制。提高 Queue Depth 可让固件重排请求，但也会放大单个请求的等待时间。

## 3. Zone 与外圈速度

外圈磁道周长更大，可容纳更多扇区。Zoned Bit Recording 让不同半径区域拥有不同扇区数，因此顺序吞吐可能随 LBA 区域变化。磁盘“前半段”和“后半段”性能不完全一致。

## 4. CMR 与 SMR

### 4.1 CMR

Conventional Magnetic Recording 的磁道相对独立，可直接更新目标区域，随机写行为更可预测。

### 4.2 SMR

Shingled Magnetic Recording 像瓦片一样让磁道部分重叠，提高面密度。改写一条磁道可能影响相邻磁道，因此通常按 Zone 处理：

```text
修改少量数据
→ 读取受影响区域
→ 在缓存或暂存区合并
→ 重写整个带区
```

由盘管理的 SMR 对主机表现为普通块设备，但持续随机写可能触发后台整理并出现明显长尾。主机管理的 Zoned 设备则要求软件按顺序写 Zone。

## 5. Cache、Flush 与掉电语义

硬盘缓存可合并请求并提升性能。主机收到写完成不一定表示磁性介质已经稳定落盘，取决于：

- Write Cache 是否启用；
- Flush/FUA 是否被正确传递；
- 控制器、RAID 卡和硬盘是否具备掉电保护；
- 固件是否遵守持久化顺序。

数据库和文件系统依赖 Flush 顺序保证一致性。擅自关闭 Flush 或使用无保护写缓存，可能让基准测试更快却破坏持久性。

## 6. 坏扇区与重映射

设备发现不可靠物理扇区后，可将其映射到备用区域。需要区分：

- Pending：读取失败，等待后续重试或重写确认；
- Reallocated：已完成重映射；
- Uncorrectable：ECC 和重试后仍无法恢复；
- Interface CRC：更可能指向线缆/链路，而非盘片介质。

重映射数量不应脱离型号、基线和变化趋势单独解释。持续增长比单个静态值更危险。

## 7. 振动、温度与阵列重建

多盘机箱中，风扇和相邻磁盘振动会影响磁头定位。高温加速老化，过低温度也不一定理想。RAID 重建同时带来：

- 长时间顺序读写；
- 多盘并发和更高温度；
- 潜在扇区错误被集中暴露；
- 业务 I/O 与重建争用。

因此阵列重建是高风险窗口，需要控制并发、监控剩余盘健康和验证备份。

## 8. 排障证据

```bash
smartctl -x /dev/sdX
smartctl -l error /dev/sdX
dmesg -T | grep -Ei 'ata|sas|scsi|reset|timeout|medium error'
iostat -x 1
```

同时记录 HBA、Expander、背板槽位、设备序列号和错误时间。交换两块盘的位置后，如果错误跟随槽位，优先怀疑背板、线缆、电源或 HBA；如果跟随序列号，才更支持盘本体问题。

## 9. 练习与答案

**问题：为什么 HDD 顺序吞吐较高，但 4 KiB 随机 IOPS 很低？**

答案：连续扇区只需一次定位后持续传输；随机请求反复寻道和等待旋转，机械延迟远大于传输 4 KiB 本身。

**问题：SMART 中 Interface CRC Error 增长，应该首先更换盘片吗？**

答案：不应。接口 CRC 更常与线缆、连接器、背板、信号或控制器有关，应先检查传输路径并做换槽对照。
