# 服务器内存硬件从零到精通学习路线

操作系统看到的是 Byte 和 Page，CPU 内存控制器面对的是 Channel、DIMM、Rank、Bank、Row、Column 和时序。服务器“装了 1 TB 内存”只描述容量，不能说明带宽、延迟、可靠性和插法是否正确。

## 2. 五个核心问题

- 容量：每个 Socket、Channel、DIMM 最大支持多少；
- 带宽：启用了多少 Channel、每 Channel 数据率多少；
- 延迟：时序、队列、Row Hit/Miss 和 NUMA 路径；
- 可靠性：ECC、Scrub、Spare、Mirror 和错误隔离；
- 兼容性：CPU SKU、主板、DIMM 类型、Rank、数量和固件矩阵。

## 3. 带宽的初步计算

典型 DDR Channel 数据总线宽度为 64 bit，即每次数据传输 8 Byte。简化理论带宽：

```text
单 Channel 带宽 = Data Rate（MT/s）× 8 Byte
Socket 带宽 = 单 Channel 带宽 × 有效 Channel 数
```

例如 4800 MT/s × 8 Byte ≈ 38.4 GB/s/Channel。它是理论数据率，不含命令、刷新、冲突、读写切换和软件效率损失；ECC 物理位宽也不等于应用可用数据额外增加。

## 4. 容量和带宽不是一回事

两台服务器都装 512 GB：

```text
A：每个 Channel 均匀 1 DIMM
B：少数 Channel 插高容量 DIMM，其余空闲
```

A 通常能利用更多 Channel 并行带宽。B 容量相同，但可用内存并发较低。容量规划必须同时给出 DPC、Channel Population 和 NUMA 分布。

## 5. 学习验收

- 能从 CPU 和主板手册确定 DIMM 插槽顺序；
- 能区分 Channel、Slot、DIMM、Rank、Chip、Bank；
- 能计算理论带宽并解释为何实测较低；
- 能解释 1DPC/2DPC、Rank 和频率降档；
- 能区分 Correctable 与 Uncorrectable Error；
- 能把 BMC SEL、EDAC、MCE 和 DIMM FRU 对应到具体插槽。

## 6. 练习与答案

**问题：总容量相同，为什么 8 条 DIMM 可能比 2 条更快？**

答案：前提是它们分布在更多独立 Memory Channel。更多 Channel 可并行传输；若只是同一 Channel 增加第二条 DIMM，容量增加但频率可能下降。
