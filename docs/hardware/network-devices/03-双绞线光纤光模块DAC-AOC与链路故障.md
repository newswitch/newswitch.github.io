# 双绞线、光纤、光模块、DAC、AOC 与链路故障

端口和模块外形相同，不代表速率、Lane、波长、距离和 FEC 兼容。物理链路选型应从“端口标准—模块—介质—距离—配线—对端”完整校验。

## 1. 常见介质

| 介质 | 典型特点 | 主要约束 |
| --- | --- | --- |
| 双绞线 | 成本低、部署普遍 | 类别、距离、串扰、功耗 |
| DAC | 铜缆直连、低成本低延迟 | 距离短、线径粗、弯曲和端口兼容 |
| AOC | 两端带光电转换的有源线缆 | 整根更换、功耗、长度固定 |
| 多模光纤 | 短距数据中心常见 | OM 等级、波长、连接器、模态带宽 |
| 单模光纤 | 长距离和高带宽 | 光预算、波长、连接器与清洁度 |

同一类型内部也有多种标准，不能只凭“都是 QSFP”或“都是 LC”判断兼容。

## 2. 模块外形与电气 Lane

SFP、QSFP、OSFP 等首先是封装/接口家族。一个高速模块可能由多条 Lane 组成，也可能通过 Breakout 拆成多个逻辑端口：

```text
一个 4-Lane 端口
→ 作为一个聚合高速链路
或
→ Breakout 为 4 个较低速率端口
```

交换机配置、线缆和对端必须使用同一 Lane 模式。仅修改接口名称不能改变不支持的物理组合。

## 3. 光链路预算

```text
接收功率 = 发射功率
         - 光纤损耗
         - 连接器/熔接/配线架损耗
         - 工程余量
```

接收功率必须位于模块接收范围：

- 太低：误码、Link Flap 或无法建立；
- 太高：接收端过载，也会异常；
- 接近边界：温度和老化后可能变得不稳定。

不能只看“有光”。应同时比较 Tx/Rx、对端反向数据和阈值。

## 4. DOM/DDM 指标

常见数字诊断信息：

- Module Temperature；
- Supply Voltage；
- Tx Bias Current；
- Tx Optical Power；
- Rx Optical Power；
- Alarm/Warning Threshold。

DOM 是重要证据但不是绝对仪器：厂商校准、模块类型和读取实现会影响精度。读取不到 DOM 也可能是模块、驱动或平台能力限制。

## 5. 污染、弯曲与极性

- 光纤端面微小灰尘会产生明显插损和反射；
- 超过最小弯曲半径会增加损耗甚至损伤；
- Tx/Rx 极性错误会导致无链路；
- MPO/MTP 还需确认 Key、极性方案和 Lane 映射；
- 配线架、耦合器和熔接点都进入光预算。

清洁必须使用合适工具并避免直视激光接口。

## 6. DAC 与 AOC 选型

### 6.1 DAC {/* #dac */}

优点是成本和功耗较低，适合机柜内短距连接。高速、较长 DAC 更粗更硬，对布线和端口机械受力要求更高；被动/主动 DAC 的支持矩阵不同。

### 6.2 AOC {/* #aoc */}

AOC 更轻、距离更长、抗电磁干扰，但两端模块与线缆一体，单点损坏通常整根更换，也不便通过普通配线架灵活跳接。

## 7. 模块兼容与 Vendor Coding

设备可能校验模块 EEPROM 中的厂商、部件号和能力。第三方模块即使光电参数符合，也可能：

- 被拒绝启用；
- 只能以部分速率运行；
- 无法读取 DOM；
- 升级系统或端口固件后失效。

生产选型要记录交换机 OS、NIC 固件、模块型号、线缆长度和 FEC 组合，而不是只记录“100G 光模块”。

## 8. 物理链路排障矩阵

| 现象 | 优先证据 |
| --- | --- |
| 完全 Link Down | 双方配置、模块识别、极性、Tx/Rx、LOS |
| 偶发 Link Flap | 光功率边界、温度、接触、FEC、固件 |
| CRC/FEC 增长 | 模块、线缆、端面、SerDes、对端端口 |
| 单向不通 | Tx/Rx、极性、单纤组件、ACL 之外的物理计数 |
| 升速后不稳定 | 介质等级、信号预算、FEC、Lane/Breakout |

交叉替换要一次只改变一个变量，并给每个模块、跳纤和端口贴唯一标识。

## 9. 常用观测

```bash
ethtool eth0
ethtool -m eth0
ethtool -S eth0
ip -s link show dev eth0
```

交换机侧也要同步读取端口、FEC、模块 DOM 和 Flap 时间。主机单侧正常不能证明端到端物理链路正常。

## 10. 练习与答案

**问题：Rx Power 比告警下限高一点，链路是否一定稳定？**

答案：不一定。阈值不是性能裕量，温度、污染、弯折和老化会继续改变功率；还需看 FEC/误码增长和两端趋势。

**问题：为什么同样外形的两个 QSFP 模块不能直接互换？**

答案：封装相同不代表速率、Lane、波长、调制、FEC、距离、介质和平台编码兼容，必须核对完整规格与设备支持矩阵。
