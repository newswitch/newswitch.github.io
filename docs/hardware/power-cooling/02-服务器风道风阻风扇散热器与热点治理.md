# 服务器风道、风阻、风扇、散热器与热点治理

服务器风扇不是简单“把温度吹低”。气流必须穿过正确部件并克服散热器、DIMM、线缆、硬盘背板和滤网形成的风阻。总风量看似足够，旁路和回流仍可能让某个 VRM、DIMM 或网卡过热。

## 1. 热量怎样离开芯片

```text
Silicon Junction
→ Package / Heat Spreader
→ TIM
→ Heat Sink
→ Airflow
→ Hot Aisle
→ Facility Cooling
```

每一段都有热阻。散热器安装压力、TIM 老化和接触不均会让芯片到散热器之间形成额外温差。

## 2. 气流与压差

风扇产生压差推动空气经过阻力路径。实际工作点由风扇曲线与系统阻抗曲线交点决定：

- 提高风扇转速通常增加风量和静压，也显著增加功耗与噪声；
- 散热器鳍片更密能增加换热面积，也增加风阻；
- 滤网积尘、线缆遮挡、空挡板缺失都会改变系统阻抗；
- 风扇空转标称风量不能代表装入机箱后的实际风量。

## 3. 串联部件与预热

气流经过前部设备后温度升高，后部设备收到的不是机房入口温度：

```text
冷空气
→ Drive Backplane
→ DIMM/CPU
→ GPU/NIC/VRM
→ 热空气
```

实际布局因机型不同。后置 NIC、PSU 和 Riser 常处于已预热气流中，需要按最差负载验证。

## 4. 风道常见问题

- 缺少 Air Shroud 或盲板，空气绕过散热器；
- 线缆束挡住 DIMM/NIC 进风；
- 风扇型号或旋向不一致；
- Riser、GPU 或硬盘改变原设计阻抗；
- 机柜冷热通道回流；
- 相邻高功率设备排风被再次吸入；
- 滤网和散热鳍片积尘。

加风扇不一定修复短路风道，先确保空气走对路径。

## 5. 风扇控制

BMC 根据温度传感器、设备配置和策略控制 PWM。需要关注：

- Fan Zone 与传感器映射；
- 传感器故障后的 Fail-safe 转速；
- 第三方 PCIe 卡是否向 BMC 暴露正确散热需求；
- 固件升级是否改变风扇曲线；
- 风扇冗余失效后剩余风量。

手工固定低转速可能短期安静，却失去随负载和故障升速的保护。

## 6. 温度指标不要混淆

- Inlet：服务器进风温度；
- Outlet：排风温度；
- Junction/Die：芯片内部温度；
- Board/Ambient：板上传感器附近温度；
- DIMM/NVMe/NIC/VRM：各部件自己的热点。

同一服务器可能 Inlet 正常而某个 NIC 控制器过热。平均温度无法替代每个关键部件的最大值和变化趋势。

## 7. 热节流与长尾

```text
温度升高
→ 风扇升速
→ 达到热/功率阈值
→ 芯片降低频率或限制功耗
→ 服务时间增长
```

如果不同节点同一任务耗时差异周期性变化，应对齐温度、频率、风扇、功耗和机柜位置。热问题常表现为性能问题，而不是立即宕机。

## 8. 验收方法

1. 记录所有风扇、温度、功率和频率基线；
2. 使用真实最坏组合负载，而非只压 CPU；
3. 覆盖风扇故障、较高 Inlet 和冗余电源模式；
4. 检查前后、左右和不同高度服务器差异；
5. 观察稳态足够长时间，等待整个热系统达到平衡；
6. 验证没有 Throttle、错误增长和异常风扇振荡。

任何遮挡、断风扇等故障实验都应在厂商允许范围和可控测试环境执行。

## 9. 练习与答案

**问题：把所有风扇固定到 100% 是否就是最佳散热方案？**

答案：不一定。它会增加功耗、噪声和风扇磨损，且无法修复旁路、回流和接触热阻；生产应使用验证过的控制曲线和正确风道。

**问题：BMC 的 Inlet 只有 24°C，为什么 NVMe 仍然热节流？**

答案：Inlet 只代表进风点。NVMe 可能位于高阻或预热区域，也可能缺少局部气流、散热片接触不良或自身持续写入发热。
