# 服务器供电与散热从零到精通学习路线

服务器稳定运行需要同时满足电力和热力约束。PSU 标称瓦数足够，不代表 PDU、冗余、瞬态、线缆和 VRM 都有余量；芯片温度未到关机阈值，也可能已经因功耗或局部热点降频。

1. [从机房供电、PDU、PSU 到 VRM 的电力路径与功率预算](./01-机房供电-PDU-PSU-VRM与功率预算.md)
2. [服务器风道、风阻、风扇、散热器与热点治理](./02-服务器风道风阻风扇散热器与热点治理.md)

4. [风冷、后门换热、冷板液冷与浸没式液冷](./04-风冷后门换热冷板液冷与浸没式液冷.md)

## 2. 两条必须同时满足的路径

```text
电力：市电/UPS → PDU → PSU → 电源平面 → VRM → 芯片
热力：芯片 → TIM → 散热器/冷板 → 风/冷却液 → 机房散热系统
```

电力路径决定能否稳定供能，热力路径决定产生的热是否能持续带走。任何一条达到边界，硬件都可能限频、复位或关机。

## 3. 不能只看平均功耗

还要关注：

- 启动浪涌与 GPU/CPU 瞬态；
- PSU 在 N+1 故障后的单模块负载；
- PDU 单相/三相的相位平衡；
- 海拔和进风温度导致的 Derating；
- VRM、电源连接器和线缆电流；
- 风扇失效和滤网积尘；
- 冷板流量、压差、供回水温差；
- 芯片、HBM、DIMM、NIC、SSD 和 VRM 的局部温度。

## 4. 性能与可靠性的交点

```text
温度或功耗接近上限
→ DVFS / Power Cap / Thermal Throttle
→ 频率下降
→ 任务时间延长
→ 持续发热时间增加
```

这会形成“设备没有报错但业务变慢”的故障。需要把功率、温度、频率、Throttle Reason 和业务延迟放在同一时间线。

## 5. 学习验收

- 能计算单机、机柜和冗余故障下的功率余量；
- 能区分分布式 PSU、Power Shelf、12V/48V Busbar、UPS 与 BBU；
- 能区分 AC 输入、PSU 输出、主板 Rail 与芯片功耗；
- 能解释 VRM、Power Good、瞬态和 Derating；
- 能识别短路风道、回流、风阻和局部热点；
- 能解释冷板、CDU、一次/二次环路和露点；
- 能比较风冷、后门换热、冷板和浸没式液冷的设施边界；
- 能从 BMC/GPU/CPU 证据判断热节流和功率节流。

## 6. 练习与答案

**问题：双 3000 W PSU 是否表示服务器可以稳定消耗 6000 W？**

答案：通常不是。双 PSU 往往用于冗余或分担负载，N+1 设计要求任意一个 PSU/电源路径失效后剩余单元仍能支撑允许功耗，还要考虑输入电压、效率和 Derating。

**问题：CPU 温度低于最高温度，为什么频率仍下降？**

答案：可能触发封装功耗、VRM、电流、平台功率或局部热点限制，而不是核心温度上限。应查看实际频率、功耗限制和 Throttle Reason。
