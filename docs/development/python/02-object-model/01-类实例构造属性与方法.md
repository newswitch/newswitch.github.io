# 类、实例、构造、属性与方法

类把状态与操作组织在同一个边界内。创建一个实例，不只是给字典换一种写法：类型可以约束对象怎样初始化、哪些状态允许改变，以及调用方能够依赖什么行为。

## 1. 类与实例分别保存什么

执行 `class` 会创建类对象，调用类通常会创建实例。实例属性一般保存每个对象自己的状态；类属性属于类，实例读取同名属性时可能沿类的继承关系找到它。

`self` 是约定名称，不是关键字。读取 `instance.method` 时，普通实例方法会绑定接收对象；调用 `instance.method(x)` 可理解为向函数同时传入实例和 `x`。`@staticmethod` 不绑定实例，`@classmethod` 绑定类，后者适合需要保留子类类型的替代构造入口。

## 2. 完整示例

```python title="objects_instance.py"
class Worker:
    category = "batch"

    def __init__(self, name, capacity=1):
        if capacity < 1:
            raise ValueError("capacity must be positive")
        self.name = name
        self.capacity = capacity
        self.jobs = []

    def submit(self, job):
        if len(self.jobs) >= self.capacity:
            raise RuntimeError("worker is full")
        self.jobs.append(job)

    @classmethod
    def single(cls, name):
        return cls(name, capacity=1)

def main():
    first = Worker.single("a")
    second = Worker.single("b")
    first.submit("job-1")
    print(first.name, first.jobs)
    print(second.name, second.jobs)
    print(first.category, second.category)
    print(first.submit.__self__ is first)
    try:
        first.submit("job-2")
    except RuntimeError as error:
        print(error)

if __name__ == "__main__":
    main()
```

```text title="objects_instance.out"
a ['job-1']
b []
batch batch
True
worker is full
```

`jobs` 在每次初始化时创建，所以实例互不共享。如果改成类体里的 `jobs = []`，并通过实例调用 `append`，操作的可能是同一个类属性列表。给某个实例写 `instance.category = ...` 又是另一件事：通常建立实例属性，遮蔽类属性，不会改掉其他实例看到的类属性。

## 3. 构造不是只有 init

常规创建路径先通过 `__new__` 获得实例，再用 `__init__` 初始化；`__init__` 必须返回 `None`，不是返回实例。不可变类型的构造、自定义分配等才通常需要直接干预 `__new__`。

初始化应该建立不变量，例如容量必须为正。不要创建“已经可访问但关键字段尚未初始化”的对象，再要求每个调用方猜它是否准备好。数据库连接、线程池等需要关闭的资源，也不应只因创建一个普通领域对象就隐式启动。

## 4. 属性访问与封装

`_name` 是内部使用约定，`__name` 会触发名称改写，主要用于避免继承冲突，不是安全隔离。Python 也不能靠“私有字段”阻止进程内恶意代码。

对必须长期保持的约束，可以提供方法或属性描述符；若允许任意给 `capacity` 赋值，本例构造校验不会自动在以后再次执行。`__slots__` 能限制常规实例属性布局并影响内存，但不是一般权限机制，也不是替代状态设计的理由。

对象的接口应说明是否修改状态、失败时状态是否保持不变。示例先检查容量再添加，因此“满了”的失败不会偷偷增加任务。

## 5. 练习与答案

### 5.1 jobs 放在类体里为什么可能串数据？

答案：类体只创建一份列表；实例未遮蔽该属性时都能读取它。`append` 修改共享列表。每实例状态应在初始化里分别创建。

### 5.2 init 返回 self 可以吗？

答案：不可以，通常会抛 `TypeError`。它负责初始化；返回实例属于创建过程的另一层职责。

### 5.3 capacity 构造时通过校验，以后一定合法吗？

答案：不一定。公开赋值仍可破坏约束。需要通过受控更新接口或带校验的属性维护不变量，而不是只检查第一次输入。
