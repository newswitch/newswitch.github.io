# Gin 路由、分组、路径参数、404 与 405

路由既决定 Handler 选择，也决定权限边界与指标标签。理解注册时的组合规则，可以避免接口漏鉴权、方法不一致和路径编码歧义。

## 1. 方法与路径共同匹配

GET /tasks/:id 与 POST /tasks 是不同路由；:id 表达单段参数，*path 捕获剩余路径。路径参数是未经业务验证的输入，不是数据库访问权限。

Group 组合前缀和中间件，注册时形成最终 Handler 链。应先建立认证分组，再注册受保护接口；不要假定后面补一次 Use 会追溯修改此前注册的全部路由。

## 2. 路由实验

```bash
cd examples/gin/service-lab
go run ./cmd/webdemo -case routing
```

```text
status=200
id=t1
```

完整代码与断言见 [service-lab](https://github.com/newswitch/newswitch.github.io/tree/main/examples/gin/service-lab)。

实际应用把读接口放在 task:read 分组，写接口放在 task:write 分组。认证只证明身份，GetTask 仍按 tenant 与 ID 查询，不能根据 :id 单独读取。

## 3. 404、405 与重定向

未找到路径通常返回 404；是否为路径存在但方法不匹配返回 405，受 HandleMethodNotAllowed 等配置影响。默认行为、Allow 头以及自定义 NoRoute/NoMethod 应用测试确认。

尾斜杠与路径规范化可能触发重定向。写接口、签名 URL 和代理链需要明确是否允许这些变化，不要把所有路径都偷偷 clean 成另一个资源。

## 4. 路径编码与观测

URL.Path、RawPath、EscapedPath 与解码参数的关系要按 Engine 配置理解。权限判断、缓存 key 和路由选择必须用一致规范，避免双重解码或 encoded slash 带来差异。

指标用 /tasks/:id 之类路由模板，不用完整 /tasks/随机ID，否则序列数量随请求增长。未匹配请求统一归类 unmatched，而不是把攻击者提供的路径直接当 label。

## 5. 注册时形成的是方法树与 Handler 快照

RouterGroup 组合前缀与 handlers，注册路由时合成最终链。已有子 Group 也持有创建时的父链组合，后续修改父组并不意味着追溯更新所有子路由。

Engine.Use 会影响后续注册，并重建特定 fallback 链，但不应据此假定之前注册的业务路由都获得了新鉴权。配套 TestMiddlewareRegistrationSnapshots 显示 early 路由没有新 Header，late 路由有。

因此认证、日志与容量边界先装配，再注册业务；用路由清单与测试检查实际入口，不靠文件里“某处调用过 Use”判断全部受保护。

## 6. 默认方法行为不等于自动 REST 语义

Gin 按方法选择路由树，注册 GET 不自动等同于注册 HEAD。启用 HandleMethodNotAllowed 时，路径在其他方法树存在会产生 405，并按匹配方法构建 Allow；未启用时则可能保留 404。

尾斜杠重定向也与方法有关。本系列固定版本测试 GET /tasks/t1/ → 301，POST /tasks/ → 307；这些状态会影响客户端是否保留方法与正文。不要在写接口中依赖某个客户端偶然采用的重定向行为。

静态段、参数段与 catch-all 的组合还有注册冲突规则。路由初始化失败应在启动前暴露，运行期不要通过重写路径来猜测另一个 Handler。

## 7. 参数、模板与权限各使用什么值

c.Param("id") 是实际提取的输入；c.FullPath() 是注册模板，适合低基数指标；Request.URL.Path 是当前 URL 表示。三者用途不同，未匹配路径的 FullPath 通常为空。

ID 需要类型、范围和对象权限校验。标准化、代理重写与编码相关配置应在调用链中保持一致，不能某层按原路径签名、下一层按另一种解码结果授权。

运行以下测试核对这些区别：

```bash
go test ./internal/requestflow -run 'TestMiddlewareRegistrationSnapshots|TestMethodTreesAndRedirects' -v -count=1
```

测试包括参数模板、缺失路径、405/Allow、HEAD 与 GET/POST 重定向，使用 Recorder 直接验证路由策略，不把它当作真实代理行为。

## 8. 练习与答案

### 8.1 Group 上有鉴权就不需要资源权限吗

仍需要对象与租户级权限。

### 8.2 路径存在但方法不对一定返回 405 吗

取决于配置与注册行为，要测试。

### 8.3 Prometheus label 可以直接用实际 URL 吗

不宜，可能造成无界高基数。
