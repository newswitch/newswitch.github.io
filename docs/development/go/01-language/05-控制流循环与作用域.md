# Go 控制流 循环与作用域

控制流决定哪些状态会被修改、什么时候退出以及错误如何传播。Go 不需要多种循环关键字，但 for、range、break、continue 和局部作用域组合后仍有需要逐步推理的边界。

## 1. 从一次迭代看状态变化

for 可以有初始化、条件和后置语句，也可以只保留条件。range 遍历数组、Slice、Map、字符串、Channel 等时，得到的值和退出方式依对象而不同。循环中的 break 通常只退出最近对应结构，多层退出要明确使用标签或返回。

对整数使用 range 从 0 开始生成迭代值；对字符串 range 产生码点和字节偏移，不是每个字节。对 Map 不保证稳定迭代顺序。把这些不同迭代都理解成“按顺序遍历下标”会产生错误。

```go
total := 0
for i := range 5 { // 0、1、2、3、4
    if i%2 != 0 { continue }
    total += i
}
state := "NEW"
switch state {
case "NEW":
    fmt.Println("can claim")
case "SUCCEEDED", "FAILED":
    fmt.Println("finished")
default:
    fmt.Println("other state")
}
```

以上为 main 内片段，需导入 fmt。Go 的 switch 匹配后默认退出分支，不会默认继续落入下一分支；fallthrough 有特殊的显式继续语义。赋值 `=` 与比较 `==` 也不能混用。

## 3. 闭包和循环边界

循环变量语义同时取决于工具链、模块的 go 语言版本与声明方式。采用 Go 1.22 及以后语义并在循环中声明的变量，与旧版复用同一个变量的规则不同；不要把“所有闭包一定共享同一个 range 变量”当成永远适用。也不能反过来认定所有循环捕获都安全：若复用外部变量、共享指针或引用底层容器，仍可能竞争。

包含重试的循环要有次数、时间预算与取消出口。条件永远为真且依赖不返回时，业务就可能无限阻塞；使用 sleep 只能改变节奏，不能提供退出协议。

## 4. range 的变量副本与容器内容要分开

遍历 Slice 得到的元素值通常是副本。对结构体副本修改普通字段，不会写回原切片；需要写回时用索引访问原元素。若元素本身是指针，复制指针后仍可修改共享对象。

遍历过程中 append 不应被当成“自动把新增项全部加入本轮任务”。range 对遍历范围有自己的求值规则，底层数组是否重新分配又会影响共享修改。需要可增长工作队列时，应使用显式的队列消费循环，并给队列与总任务数设上限。

遍历字符串得到字节偏移和码点，遍历 Channel 直到关闭才结束；nil Channel 不会自然结束。先确定对象，再解释 range，不能把它统一理解为数组下标循环。

## 5. 新版循环变量与外部复用变量的实际对照

```bash
go run ./cmd/foundation-lab -mode language
go test ./internal/foundation -run TestLanguage -v -count=1
```

在 Go 1.27 语言语义下，实验中使用 i := range 3 创建的闭包依次得到 [0,1,2]；使用循环外 j 并以 j = range 3 赋值，闭包都读到最终的 2。这是串行调用，无需用不确定的 Goroutine 调度观察结果。

新语义解决特定的迭代变量复用问题，不会复制指针指向的对象，也不会同步闭包共享的 Map。维护旧模块时还要核对 go 指令，不能只看本机工具链版本。

## 6. 退出、重试与状态迁移要有明确终点

break 退出最近的对应循环或 switch；continue 进入相应循环的下一轮；return 结束当前函数。循环里嵌套 select 时，select 内的 break 不一定退出外层 for，使用标签或返回值表达意图更清楚。

重试应区分可重试错误、最大次数、总预算与退避；每次尝试还要继承剩余 Context。只在两次尝试之间检查取消，无法中断一个永不返回的 I/O。

状态机使用 switch 时，把允许转换、终态与未知状态写清。默认不 fallthrough 有助于保持一次转换的局部性；不要让输入任意字符串直接落入“其他状态也当成功”的分支。

## 7. 练习与答案

### 7.1 Map 的 range 顺序能作为分页顺序吗

不能。要先定义排序键并排序，或让数据库按稳定条件返回分页。

### 7.2 if 内短声明的 n 会自动替换外层 n 吗

不会自动如此；要看是否处于同一作用域以及是否发生新声明。实验中它遮蔽外层变量。

### 7.3 循环每轮有 sleep 就能保证可取消吗

不能。必须检查取消信号，并让阻塞调用、发送和接收也响应取消。
